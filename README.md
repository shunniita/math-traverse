# 数学縦走 ── 1+1=2 からオイラーの等式へ

> $e^{i\pi} + 1 = 0$
>
> この式の意味を、ペアノの公理から一歩も飛ばさずに理解しに行く本。

## これは何か

小学校の算数から大学教養までの数学を、**ジャンル別の全9巻+EX**に再編した数学書(執筆中)。ふつうの教科書と違うのは、次の二つの約束を全巻で守ることです。

1. **すべての定理は、それ以前に示した定理か、明示した仮定だけから導出する。**
   学校教科書が黙って通り過ぎる循環論法(例: lim sin x/x = 1 の面積による証明)は、構造の段階で切断してあります。
2. **前借りは隠さない。**
   後の巻の結果を先に使うときは〔借用: ○巻△章〕という**借用証書**を貼り、回収する場所を明記します。本書の装備で登り切れない山(リーマン予想など)には**登頂断念証明書**を発行し、どこまで登れて頂上がどう見えるかを正直に書きます。

各巻はジャンルの山であり、それぞれに山場(ピーク)があります。読者は麓(1+1=2)から尾根伝いに全山を歩き通すこともできるし、依存グラフを頼りに好きな山だけ登ることもできます。だから**縦走**。

$$e^{i\pi} + 1 = 0$$

この本は、この一行の意味を、1+1=2 から一歩も飛ばさずに理解しに行くための本である。

学校教科書は、しばしば黙って循環論法を通り過ぎる。lim sin x/x = 1 の面積による証明はその代表格で、扇形の面積 → 円の面積 → 積分 → sin の微分 → …と、輪が自分自身に戻ってきてしまう。この本は二つの約束だけを全巻で守ることで、その輪を断ち切る。

1. **すべての定理は、それ以前に示した定理か、明示した仮定だけから導出する。**
2. **前借りは隠さない。** 後の巻の結果を先に使うときは〔借用: ○巻△章〕という**借用証書**を貼り、回収する場所を明記する。

全9巻+EXは、それぞれがジャンルの山であり、それぞれに山場(ピーク)がある。読者は麓(0巻)から尾根伝いに全山を歩き通すこともできるし、依存グラフを頼りに好きな山だけ登ることもできる ── だから**縦走**。設計思想の全体は [引き継ぎ資料.md](../引き継ぎ資料.md)、章・節レベルの設計図は [数学書_全巻目次案.md](../数学書_全巻目次案.md) を参照。

# 0巻 3章　論理・命題・証明 ── 正しさを運ぶ規則

**この章の仕事。** 数学では、正しそうな図や大量の実験だけでは定理にならない。何を仮定し、どの規則で、どの結論まで進んだかを追跡できて初めて証明になる。この章では、その交通法規を作る。

**依存台帳**
- 〔前提〕本巻1章(集合)、2章(関係・写像)
- 〔借用: 本巻4章〕自然数・後者写像・帰納法の正式な土台。3.7では証明法の形だけを先に見る
- 供給先: 本巻4章以降のすべての定義・定理・証明

**採用する論理。** 本書は、各命題が真か偽のどちらか一方であるとする古典二値論理を使う。別の論理体系もあるが、この縦走では古典論理を共通装備にする。

---

## 3.1　命題と真偽

**命題**とは、真か偽かが決まる文である。

- 「空集合はどんな集合の部分集合でもある」は命題であり、真である。
- 「$a\in A$」は、a と A が何を指すか決まれば命題になる。
- 「この集合は大きい」は、何を大きいとするか決まっていないので、そのままでは命題にならない。
- 「x は A の元である」は、x が決まるまでは穴の空いた文である。

最後のような文を**述語**と呼ぶ。x に具体的なものを入れたり、「すべての x について」と範囲を閉じたりすると命題になる。

命題 P が真であることを証明するとは、採用した出発点から、認められた推論規則だけを使って P まで道をつなぐことである。

ここで、本書全体の品札を整理しておく。

- **定義**: 言葉や記号の意味を決める。真偽を証明する対象ではない。
- **公理**: その理論の出発点として採用する命題。
- **定理**: 定義・公理・既証明の定理から証明された命題。
- **予想**: 真だと期待されているが、まだ証明されていない命題。

「正しいと決めたこと」と「正しいと分かったこと」を混ぜない。定義を証明したり、予想を定理のように使ったりしない。この区別が本書の借用証書制度の土台である。

## 3.2　論理結合子 ── 文から新しい文を作る

二つの命題 P、Q から新しい命題を作る操作を**論理結合子**と呼ぶ。

### かつ

$P\land Q$ は「P かつ Q」で、P と Q が両方とも真のときだけ真である。

### または

$P\lor Q$ は「P または Q」で、少なくとも一方が真なら真である。数学の「または」は、特に断らない限り両方が真の場合も含む。

### ではない

$\lnot P$ は「P ではない」で、P の真偽を反転する。

### ならば

$P\Rightarrow Q$ は「P ならば Q」である。P が真なのに Q が偽になる場合だけ偽とする。

| P | Q | $P\land Q$ | $P\lor Q$ | $P\Rightarrow Q$ |
|---|---|---|---|---|
| 真 | 真 | 真 | 真 | 真 |
| 真 | 偽 | 偽 | 真 | 偽 |
| 偽 | 真 | 偽 | 真 | 真 |
| 偽 | 偽 | 偽 | 偽 | 真 |

含意の下二行は最初に引っかかりやすい。P が偽なら「P ならば Q」という約束を破る場面そのものが起きていないので、含意は真とする。1章で $\varnothing\subseteq A$ がつねに成り立ったのも同じ構造である。

$P\Rightarrow Q$ のとき、P は Q の**十分条件**、Q は P の**必要条件**である。P があれば Q まで行くには十分で、Q がなければ P は起こりえない。

### 同値

P から Q へも、Q から P へも進めるとき

$$P\Longleftrightarrow Q$$

と書き、「P と Q は同値」と呼ぶ。同値を証明するには、二方向を別々に示さなければならない。

## 3.3　逆・裏・対偶 ── 似た文を取り違えない

命題 $P\Rightarrow Q$ に対して、次の三つを作れる。

- **逆**: $Q\Rightarrow P$
- **裏**: $\lnot P\Rightarrow\lnot Q$
- **対偶**: $\lnot Q\Rightarrow\lnot P$

元の命題と対偶はつねに同値である。一方、逆や裏が元の命題と同じ真偽になるとは限らない。

写像 $f:A\to B$ について

$$a_1=a_2\quad\Longrightarrow\quad f(a_1)=f(a_2)$$

はつねに真である。同じ入力に同じ規則を適用すれば、同じ出力になるからだ。しかし逆

$$f(a_1)=f(a_2)\quad\Longrightarrow\quad a_1=a_2$$

は、f が単射のときだけ成り立つ。逆を勝手に使うと、写像の情報を捏造してしまう。

対偶は、元の命題を別方向から攻める武器になる。$A\subseteq B$ を示す代わりに

$$x\notin B\quad\Longrightarrow\quad x\notin A$$

を示してもよい。

## 3.4　全称と存在 ──「すべて」と「ある」を記号にする

述語 P(x) の変数 x が集合 A を動くとする。

**全称命題**「すべての $x\in A$ について P(x)」を

$$\forall x\in A,\ P(x)$$

と書く。

**存在命題**「P(x) を満たす $x\in A$ が少なくとも一つ存在する」を

$$\exists x\in A,\ P(x)$$

と書く。

存在するものが一つだけであることを言いたいときは、存在と一意性を分けて証明する。

$$\exists!x\in A,\ P(x)$$

という記号も使うが、これは「少なくとも一つある」と「二つあれば等しい」をまとめた略記である。

量化記号の順番は意味を変える。写像 $f:A\to B$ の条件

$$\forall a\in A,\ \exists b\in B,\ f(a)=b$$

では、入力 a ごとに b を選んでよい。一方

$$\exists b\in B,\ \forall a\in A,\ f(a)=b$$

では、すべての入力が同じ一つの b へ送られる。前者と後者は別の命題である。

## 3.5　命題の否定 ── 量化記号のド・モルガン

「すべての x が P を満たす」の否定は、「すべての x が P を満たさない」ではない。反例が一つあれば全称命題は壊れる。

$$\lnot\left(\forall x\in A,\ P(x)\right)\Longleftrightarrow\exists x\in A,\ \lnot P(x)$$

「P を満たす x がある」の否定は、「どの x も P を満たさない」である。

$$\lnot\left(\exists x\in A,\ P(x)\right)\Longleftrightarrow\forall x\in A,\ \lnot P(x)$$

1章のド・モルガンの法則と同じ形をしている。和集合は「または」、積集合は「かつ」、補集合は「ではない」に対応していた。集合の法則と論理の法則は別々の偶然ではなく、元 x を通して同じ構造を見ていたのである。

否定を書くときは、文頭に「ではない」を貼るだけで済ませず、量化記号を一つずつ反転して否定を中へ運ぶ。たとえば

$$\forall x\in A,\ \exists y\in B,\ R(x,y)$$

の否定は

$$\exists x\in A,\ \forall y\in B,\ \lnot R(x,y)$$

である。「どの x にも相手がいる」を壊すには、「誰を連れてきても相手がいない x」を一つ見つければよい。

## 3.6　証明の作法

### 直接証明

仮定から推論を重ね、そのまま結論へ進む。

**例** $A\subseteq B$ かつ $B\subseteq C$ なら $A\subseteq C$。

*証明。* 任意の $x\in A$ を取る。$A\subseteq B$ より $x\in B$。さらに $B\subseteq C$ より $x\in C$。どの $x\in A$ も C に入るので $A\subseteq C$。∎

この短い証明にも作法がある。全称命題を示すために任意の x を一つ固定し、仮定を適用し、最後に任意性を使って全体へ戻した。

### 対偶による証明

$P\Rightarrow Q$ を直接示しにくいとき、同値な対偶 $\lnot Q\Rightarrow\lnot P$ を示す。

**例** 合成写像 $g\circ f$ が単射なら、f は単射である。

*証明。* 対偶を示す。f が単射でないとすると、$a_1\neq a_2$ なのに $f(a_1)=f(a_2)$ となる二つの入力がある。両辺に g を適用すれば

$$g(f(a_1))=g(f(a_2))$$

となる。したがって $g\circ f$ も単射ではない。∎

### 背理法

示したい命題 P が偽だと仮定し、その仮定から矛盾を導く。古典論理では、$\lnot P$ が矛盾を生むなら P は真である。

**例** 単射でない写像は逆写像を持たない。

*証明。* f は単射でないのに逆写像 $f^{-1}$ を持つと仮定する。すると $a_1\neq a_2$ かつ $f(a_1)=f(a_2)$ となる入力がある。両辺に $f^{-1}$ を適用すれば $a_1=a_2$ となり、$a_1\neq a_2$ と矛盾する。∎

### 同値の証明

$P\Longleftrightarrow Q$ は、$P\Rightarrow Q$ と $Q\Rightarrow P$ の二本に分ける。「同様」は、二方向の仮定と結論が本当に入れ替わるときだけ使う。

### 反例

全称命題が偽だと示すには、条件を満たすのに結論が壊れる例を一つ出せばよい。百個の成功例は全称命題を証明しないが、一個の反例は全称命題を倒す。

## 3.7　数学的帰納法 ── 無限の階段を一度に登る

自然数についての命題 P(n) を、すべての n で示したい。無限個を一つずつ確認することはできない。そこで二つの仕事に分ける。

1. 最初の段で P(0) が成り立つことを示す。
2. 任意の段 n について、P(n) が成り立つなら次の段 P(S(n)) も成り立つことを示す。

すると、P は自然数のすべての段で成り立つ。これが**数学的帰納法**である。

$$P(0),\qquad \forall n\in\mathbb{N},\ P(n)\Rightarrow P(S(n))$$

**〔借用証書: 0巻4章〕** ここでは $\mathbb{N}$、0、次の数を作る写像 S がまだ正式に定義されていない。また「最初と次があれば全部を覆う」という保証そのものが、ペアノの公理の一つである。いまは証明の形を先に見た。担保は次章で直ちに渡す。

帰納法は、有限個の実験から一般則を推測する「帰納」とは違う。基底段と帰納段を証明したときに限り、無限個の命題が一本の論証で覆われる。

## 3.8　コラム: 「すべての馬は同じ色」── 帰納法はどこで壊れたか

次の偽証明は、帰納法の形をよく真似ている。

> n 頭の馬はすべて同じ色だと仮定する。n+1 頭の馬から最後の一頭を外せば、残る n 頭は同じ色。今度は最初の一頭を外せば、別の n 頭も同じ色。二組には共通の馬がいるので、n+1 頭すべて同じ色である。

基底段では、一頭の馬が自分と同じ色なのは確かである。帰納段もそれらしく見える。壊れているのは、一頭から二頭へ進むところだ。

二頭の馬から一頭ずつ外すと、二つの組に共通する馬は一頭もいない。「共通の馬を介して色が一致する」という橋が存在しない。n が十分大きい場面でだけ働く議論を、最初の帰納段にまで無断で伸ばしていた。

証明は、形が似ているだけでは通らない。各推論が、必要な仮定をその場で満たしているかを点検する。帰納法は無限を扱う強力な武器だが、壊れた橋を飛び越える免許ではない。

# 0巻 2章　二項関係・写像 ── ものとものを結ぶ

**この章の仕事。** 集合は「何を相手にするか」を固定した。次は、その元どうしを線で結ぶ。好きなように結んだものが二項関係であり、入力一つから出力一つへ進めるように線を整理したものが写像である。

## 2.1　二項関係とは ── 直積集合から線を選ぶ

集合 A と B がある。A の元 a と B の元 b の間に何らかの関係があることを、順序対 $(a,b)$ で記録する。関係のある順序対だけを集めれば、それは $A\times B$ の部分集合になる。

**定義(二項関係)** A から B への二項関係 R とは、直積集合 $A\times B$ の部分集合である。

$$R\subseteq A\times B$$

$(a,b)\in R$ のとき「a は b と関係 R にある」といい、しばしば $aRb$ と略記する。

たとえば $A=\{a,b,c\}$、$B=\{p,q\}$ とし

$$R=\{(a,p),(b,p),(b,q)\}$$

とする。この関係では a は p と結ばれ、b は p と q の両方に結ばれ、c はどこにも結ばれていない。関係は、結び方について何も約束しない。一つから何本出てもよく、一本も出なくてもよい。

A から A への関係 $R\subseteq A\times A$ では、三つの性質が何度も現れる。

- **反射的**: どの $a\in A$ にも $aRa$ が成り立つ。
- **対称的**: $aRb$ ならば $bRa$ が成り立つ。
- **推移的**: $aRb$ かつ $bRc$ ならば $aRc$ が成り立つ。

同じ「線を引く」でも、性質は別々である。「友達である」は対称的に見えるが、推移的とは限らない。「先祖である」は推移的だが、反射的でも対称的でもない。数学では、名前の印象ではなく三条件を一つずつ点検する。

## 2.2　同値関係 ── 違うものを同じ組に入れる

反射的・対称的・推移的の三条件をすべて満たす関係を**同値関係**と呼ぶ。

同値関係は「完全に同じ」よりも柔らかい。「今回見たい特徴については同じ」と宣言する道具である。

例として、赤い丸を $r_c$、赤い三角を $r_t$、青い丸を $b_c$、青い三角を $b_t$ と略記し、札の集合

$$A=\{r_c,r_t,b_c,b_t\}$$

を考え、「色が同じ」という関係を入れる。

- どの札も自分自身と同じ色なので反射的。
- x が y と同じ色なら、y も x と同じ色なので対称的。
- x と y が同じ色で、y と z が同じ色なら、x と z も同じ色なので推移的。

したがって、これは同値関係である。

a と同値な元をすべて集めた集合を、a の**同値類**と呼ぶ。

$$[a]=\{x\in A\mid x\sim a\}$$

上の例では「赤い丸」の同値類は

$$[r_c]=\{r_c,r_t\}$$

である。同値関係を入れると、集合 A は重なりのない同値類へ分かれる。

理由も確かめておこう。反射性から、どの $a\in A$ も自分の類 $[a]$ に入る。さらに $[a]$ と $[b]$ が共通の元 z を持つなら、対称性と推移性から $a\sim b$ が従う。そのとき $x\sim a$ と $a\sim b$ をつなげられるので、$[a]$ の元はすべて $[b]$ に入る。逆向きも同じだから $[a]=[b]$ である。したがって、二つの同値類は一致するか、まったく交わらない。

同じ類の中では代表を取り替えても、今回見ている特徴は変わらない。

この「違うものを同じとみなす」は、数学の巨大な圧縮装置である。分数では $1/2$ と $2/4$ を同じ数とみなし、幾何ベクトルでは平行移動して重なる矢印を同じとみなし、時計算では12時間違う時刻を同じ位置とみなす。後の巻で何度も、ここで作った装置が静かに働く。

## 2.3　写像とは ── 入力一つに出力を一つ

二項関係は自由すぎる。一つの入力から線が二本出ることも、一本も出ないこともあった。計算の手順として使うには、入力を渡したら出力が迷わず一つ決まってほしい。

**定義(写像)** 集合 A から集合 B への写像 f とは、A の各元 a に対して、B の元 b を**ちょうど一つ**対応させる規則である。

$$f:A\to B$$

A を**定義域**、B を**終域**と呼ぶ。a に対応する唯一の元を f(a) と書く。

写像は特別な二項関係としても表せる。$G_f\subseteq A\times B$ を

$$G_f=\{(a,f(a))\mid a\in A\}$$

とすれば、各 $a\in A$ はちょうど一つの順序対の第一成分になる。この集合 $G_f$ を f の**グラフ**と呼ぶ。

本書では、定義域・終域・対応規則の三つを合わせて一つの写像とする。二つの写像が等しいとは、定義域と終域がそれぞれ一致し、すべての入力で出力も一致することをいう。

重要なのは「出力が一つ」であって、「違う入力は違う出力」とはまだ言っていない。二人が同じロッカーを割り当てられる写像は作れる。ただし一人に二つのロッカーを同時に割り当てたら、この意味での写像ではない。

具体例として

$$A=\{a,b,c\},\qquad B=\{p,q\}$$

とし

$$f(a)=p,\qquad f(b)=q,\qquad f(c)=q$$

と定める。これは写像である。b と c の出力が同じでも構わない。

## 2.4　像と逆像 ── 写像はどこへ届くか

終域 B のすべてに、実際に矢印が届くとは限らない。f が実際に出力する値を集めた集合を f の**像**と呼ぶ。

$$\operatorname{Im}(f)=\{f(a)\mid a\in A\}\subseteq B$$

先ほどの例では $\operatorname{Im}(f)=\{p,q\}=B$ である。もし $f(a)=f(b)=f(c)=p$ なら、像は $\{p\}$ だけになる。

部分集合 $S\subseteq A$ をまとめて写した集合も考えられる。

$$f(S)=\{f(a)\mid a\in S\}$$

逆向きに、$T\subseteq B$ へ送られる入力を全部集めたものを T の**逆像**と呼ぶ。

$$f^{-1}(T)=\{a\in A\mid f(a)\in T\}$$

この $f^{-1}(T)$ は、逆写像が存在しなくても定義できる。逆像は「T に着く入力を探す」操作であって、出力一つから入力一つを決める操作ではない。記号が似ているので、ここは何度でも立ち止まってよい。

## 2.5　単射・全射・全単射

写像の矢印の引き方を点検する三つの言葉を導入する。

**単射**とは、違う入力が同じ出力へ潰れない写像である。

$$f(a_1)=f(a_2)\quad\Longrightarrow\quad a_1=a_2$$

**全射**とは、終域のどの元にも少なくとも一本は矢印が届く写像である。

$$\operatorname{Im}(f)=B$$

**全単射**とは、単射かつ全射である。終域の各元に、ちょうど一本ずつ矢印が届く。

$A=\{a,b,c\}$、$B=\{p,q,r\}$ で

$$f(a)=p,\qquad f(b)=q,\qquad f(c)=r$$

なら f は全単射である。一方、終域を $B'=\{p,q,r,s\}$ に変え、同じ対応規則を使うと単射ではあるが全射ではない。対応する順序対が同じでも、終域が変われば全射かどうかは変わる。だから写像を語るとき、定義域と終域を省いてはいけない。

全単射は「二つの集合の元が一対一に対応する」という証明書になる。有限集合なら、全単射がある二集合は同じ個数の元を持つ。無限集合では、この発想が「個数」そのものの定義へ育つ(1巻の遠望)。

## 2.6　合成写像 ── 二つの手順を一本につなぐ

写像 $f:A\to B$ と $g:B\to C$ がある。f で A から B へ進み、その結果を g に渡して C へ進める。この二段の手順を一本にまとめた写像を**合成写像**と呼ぶ。

$$g\circ f:A\to C,\qquad (g\circ f)(a)=g(f(a))$$

記号では右側の f から先に働く。作文の順と見た目が逆なので注意が要る。

三つの写像がつながるとき、括弧の位置は結果を変えない。

**定理(結合則)** $f:A\to B$、$g:B\to C$、$h:C\to D$ に対して

$$h\circ(g\circ f)=(h\circ g)\circ f$$

*証明。* 任意の $a\in A$ に対して、左辺も右辺も

$$h(g(f(a)))$$

を返す。すべての入力で値が一致するので、二つの写像は等しい。∎

A の各元を動かさない写像を**恒等写像**と呼ぶ。

$$\operatorname{id}_A:A\to A,\qquad \operatorname{id}_A(a)=a$$

恒等写像は、合成における「何もしない手順」である。

## 2.7　逆写像 ── 戻れる写像と戻れない写像

写像 $f:A\to B$ の矢印をすべて逆向きにして、B から A への写像を作りたい。これが可能なのは f が全単射のとき、そしてそのときに限る。

**定理** f が全単射なら、各 $b\in B$ に対して $f(a)=b$ となる a がちょうど一つ存在する。その a を $f^{-1}(b)$ と定めれば、写像

$$f^{-1}:B\to A$$

が得られ

$$f^{-1}\circ f=\operatorname{id}_A,\qquad f\circ f^{-1}=\operatorname{id}_B$$

が成り立つ。逆に、この二式を満たす写像が存在すれば f は全単射である。実際、第一式から f の単射性が、第二式から f の全射性がそれぞれ従う。

単射でなければ、一つの出力から元の入力を一つに決められない。全射でなければ、矢印を逆向きにしたとき出発できない元が B に残る。逆写像が要求するのは、この二つの故障がどちらもないことだ。

写像の合成と逆写像は、後の数学の文法になる。関数の合成、座標変換、行列、群の演算、プログラムの連結は、どれもこの章の変奏である。

---

集合と写像が揃った。しかし「この写像は全射である」「この二つの集合は等しい」という文を、どうすれば正しく証明できるのかはまだ決めていない。次章では、文そのものを数学の対象にし、正しさを運ぶ規則を作る。

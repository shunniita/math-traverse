## この巻の読み方

この巻は、後の全巻で無言に使われる文法を先に組み立てる。集合から関係を、関係から写像を、写像を語る文から論理と証明を作る。その後でペアノの公理を採用し、加法を再帰的に定義して $1+1=2$ を証明する。最後に、自然数そのものと十進法・二進法などの表記を切り分ける。

初学者は、分からない箇所を残して1巻へ進んでもよい。後の巻で「単射」「対偶」「帰納法」などに出会ったとき、必要な節へ戻る使い方を想定している。

節レベルの目次は [数学書_全巻目次案.md](../../数学書_全巻目次案.md) を参照。

# 3巻 7章　四元数と空間の回転 ── 回転の代数化

**3巻の山場。** 複素数は平面の回転を「掛け算」にした(6章)。同じことを空間でやりたい。ハミルトンは三つ組の数で10年格闘して失敗し、四つ組で成功した。成功の代償は交換法則だった。この章では、なぜ三つ組では駄目で四つ組ならよいのかを見て、四元数で空間の回転を書き、それがオイラーの公式と同じ形をしていることを見る。

**依存台帳**
- 〔前提〕1巻10章(複素数・ケイリー=ディクソンの階段の予告) / 本巻4章(空間ベクトル・内積・外積) / 本巻5章(行列・非可換性) / 本巻6章(複素数と回転) / 2巻9章(空間の回転軸 ── 直観のみ)
- 〔借用: 4巻7章〕三角関数の加法定理・半角公式
- 供給先: 7巻(回転群・スペクトル定理の遠望)、8巻(非可換群の例)、9巻(3D グラフィックスの遠望)
- 縦糸「不可能性の証明」: 三次元の「数」は作れない(7.2節)、フルヴィッツの定理(遠望)

## 7.1　複素数の次は何か：三つ組と10年格闘したハミルトン

複素数 $a+bi$ は平面の点であり、その掛け算は回転と拡大だった。空間の点は三つ組 $(a,b,c)$ である。$a+bi+cj$ という「三元数」に掛け算を入れ、空間の回転を表せないか。

ハミルトンは1830年代からこの問題に取り組んだ。足し算は成分ごとでよい。掛け算が決まらない。$i^2=j^2=-1$ とし、$ij$ を何にすればよいか。$ij=a+bi+cj$ と置いて絶対値が積を保つ($|zw|=|z||w|$、1巻10章)ことを要求すると、矛盾が出る。彼の息子が毎朝「パパ、三つ組は掛け算できた?」と尋ね、彼は「いや、足し算と引き算しかできないんだ」と答えた、と本人が手紙に書いている。

1843年10月16日、ダブリンのブルーム橋を妻と散歩中に、彼は答えに気づいた。**四つ目の成分が要る。** $i^2=j^2=k^2=ijk=-1$。彼はこの式を橋の石に刻んだと伝えられる(コラム)。

## 7.2　なぜ3次元の「数」は作れないのか、そして4ならできるのか

**三元数が不可能な理由(初等的な部分)。** $a+bi+cj$ の形の数に、結合法則と分配法則を満たし、実数を含み、$i^2=j^2=-1$ となる掛け算を入れたい。$ij=x+yi+zj$ とおく。左から $i$ を掛けると $i(ij)=(ii)j=-j$、右辺は $xi+y(-1)+z(ij)=-y+xi+z(x+yi+zj)$。$j$ の係数を比べて $-1=z^2$、実数の範囲で不可能。だから $ij$ は $\{1,i,j\}$ の実数係数の組合せの中にない。$ij$ を収める四つ目の方向 $k$ が必要になる。

**四元数。** $q=a+bi+cj+dk$($a,b,c,d$ は実数)。掛け算は分配法則と

$$i^2=j^2=k^2=-1,\qquad ij=k,\ jk=i,\ ki=j,\qquad ji=-k,\ kj=-i,\ ik=-j$$

で定める。$ij=k$ かつ $ji=-k$。**交換法則が成り立たない。** これが代償である。結合法則と分配法則は成り立ち(規則の表で確かめられる)、絶対値 $|q|=\sqrt{a^2+b^2+c^2+d^2}$ は積を保つ: $|pq|=|p||q|$。この等式を成分で書くと「四つの平方和の積は四つの平方和」という恒等式(オイラーの四平方恒等式)になり、1巻10章の二平方の恒等式の四次元版である。1巻11章の平方剰余で触れた「すべての自然数は四つの平方数の和」(ラグランジュ)の証明の核心がこの恒等式にある。

**なぜ 4 ならよいのか(遠望)。** 絶対値が積を保つ「数」の体系(ノルム付き多元環)は、次元 1, 2, 4, 8 にしかない。フルヴィッツの定理(1898年)で、1巻10章コラムで予告した「拡張のたびに何かを失う階段」の終着駅である。証明は本書の範囲を超えるが、「三次元では不可能」の初等的な部分は上で見た。三つ組は掛け算できず、四つ組は交換できず、八つ組(八元数)は結合もできず、十六では絶対値が積を保たない。

## 7.3　四元数の演算規則 ── 可換性を生贄に捧げる

四元数を、実部 $a$ と**ベクトル部** $\vec v=(b,c,d)$ に分けて $q=(a,\vec v)$ と書くと、積の規則が一行になる。

**定理 7.1** $(a,\vec v)(b,\vec w)=(ab-\vec v\cdot\vec w,\ a\vec w+b\vec v+\vec v\times\vec w)$。

*証明。* 分配法則で展開し、$ij=k$ 等の規則を使うと、$i,j,k$ の積の部分が内積(同じ文字どうし、$-1$)と外積(異なる文字、巡回で $\pm$)に分かれる。∎

**内積と外積(4章)は、もともと四元数の積の実部とベクトル部だった。** 歴史的にもそうで、ギブスとヘヴィサイドが四元数からベクトル部の演算だけを取り出して「ベクトル解析」を作った(1880年代)。外積が交換しない($\vec v\times\vec w=-\vec w\times\vec v$)のは、四元数の非可換性の遺産である。

**共役と逆元。** $\bar q=(a,-\vec v)$、$q\bar q=|q|^2$、$q^{-1}=\dfrac{\bar q}{|q|^2}$($q\neq0$)。複素数と同じ形で、0 以外のすべての元に逆元がある。四元数は「交換法則を除いて体」であり、**斜体**(可除環)という。8巻で環の例として再登場する。

## 7.4　四元数による空間回転の表現

複素数では「$\cos\theta+i\sin\theta$ を掛ける」が回転だった。四元数では、掛けるだけでは回転にならない(左から掛けるか右から掛けるかで結果が違い、どちらも四次元の回転になる)。三次元の回転は、**両側から挟む**ことで得られる。

単位ベクトル $\vec n$(回転軸)と角 $\theta$ に対し

$$q=\left(\cos\frac\theta2,\ \sin\frac\theta2\,\vec n\right)$$

とおく。$|q|=1$ である。空間の点 $\vec p$ を純虚四元数 $(0,\vec p)$ と見て

$$(0,\vec p')=q\,(0,\vec p)\,q^{-1}$$

**定理 7.2** $\vec p'$ は、$\vec p$ を軸 $\vec n$ のまわりに角 $\theta$ だけ回転したものである。

*証明の骨格。* $\vec p$ を $\vec n$ 方向の成分と垂直成分に分ける。$\vec n$ 方向の成分は $q$ と可換($(0,\vec n)$ と $q$ は可換)なので動かない。垂直成分 $\vec u$ について、定理7.1で $q(0,\vec u)q^{-1}$ を計算すると、$\cos^2\dfrac\theta2-\sin^2\dfrac\theta2=\cos\theta$ と $2\sin\dfrac\theta2\cos\dfrac\theta2=\sin\theta$(倍角公式、4巻7章)が現れ、$\vec u\cos\theta+(\vec n\times\vec u)\sin\theta$ になる。これは $\vec u$ を $\vec n$ のまわりに $\theta$ 回転したものである。∎

角が $\dfrac\theta2$ で入る理由は、$q$ が左右から一回ずつ、合計二回作用するからである。$\theta=360$ のとき $q=-1$ で、$q$ と $-q$ は同じ回転を表す。「一回転して元に戻るのに、四元数は符号が変わる」というこの現象は、物理学でスピンの二重被覆として再登場する(遠望)。

**回転の合成は四元数の積。** 回転 $q_1$ の後に $q_2$ を行えば $q_2q_1$。回転の順序を変えると結果が変わることが、四元数の非可換性に正確に対応している。5章の行列でも回転は書けるが(3×3 の回転行列、9 個の数)、四元数は 4 個の数で済み、合成が積一回で、しかも数値誤差で「回転でなくなる」ことがない(単位四元数に正規化し直せばよい)。コンピュータグラフィックスと姿勢制御が四元数を使う理由である(コラム)。

## 7.5　オイラーの公式との響き合い

単位四元数 $q=\cos\dfrac\theta2+\vec n\sin\dfrac\theta2$ を、複素数の $\cos\theta+i\sin\theta$ と並べてほしい。$\vec n$ は $\vec n^2=-1$(定理7.1で $\vec n\cdot\vec n=1$、$\vec n\times\vec n=0$)を満たすので、$\vec n$ は「虚数単位の役」をしている。**四元数の中には、虚数単位が球面ぶん(無限に)ある。** 各単位ベクトル $\vec n$ に対し $\{a+b\vec n\}$ は複素数と同型な部分体系で、四元数は「複素数平面を軸ごとに束ねたもの」と見える。

4巻11章で $e^{i\theta}=\cos\theta+i\sin\theta$ を証明したあと、同じ級数の議論を $\vec n$ について行えば

$$e^{\vec n\theta}=\cos\theta+\vec n\sin\theta$$

となり、回転は $\vec p'=e^{\vec n\theta/2}\,\vec p\,e^{-\vec n\theta/2}$ と書ける。「回転は指数関数である」。この見方は7巻の遠望(行列の指数関数、リー群)で、回転が「小さな回転の無限回の合成」として指数関数になる、という物理と幾何の中心思想につながる。この巻の山場は、4巻の山場と遠く響き合っている。

## 7.6　コラム: ジンバルロックとアポロ計画、そしてブルーム橋の落書き

**ジンバルロック。** 空間の姿勢を三つの角(ヨー・ピッチ・ロール、オイラー角)で表すと、二つの回転軸が重なる姿勢で自由度が一つ失われ、その近くで小さな姿勢変化に大きな角の変化が要る。アポロ宇宙船の慣性航法装置はジンバル三つで組まれており、この状態を避けるためにパイロットは特定の姿勢を取れなかった。アポロ13号の事故対応でも、ジンバルロックを避ける操作が問題になった。四元数にはこの特異点がなく、現代の宇宙機・ドローン・ゲームエンジンは姿勢を四元数で持つ。

**ブルーム橋。** ハミルトンが $i^2=j^2=k^2=ijk=-1$ を刻んだという石は残っていないが、橋には1958年に記念の銘板が設置され、毎年10月16日にダブリンの数学者たちが彼の散歩道を歩く行事が続いている。「数学史上最も有名な落書き」であり、非可換な数の誕生の記念碑である。

回転が代数になった。平面では複素数、空間では四元数、そしてどちらも指数関数の形をしている。次章は幾何の武器庫(解析編)。座標化、複素数による回転、そして「反転」という円を直線に変える変換を並べる。

# 2巻 7章　三角比：直角三角形の中の比

**背骨ノード** ── ここで定義する三角比(0°〜90°)は、4巻7章で単位円により一般角へ拡張され、5巻5章の弧長(弧度法)と合流して、4巻11章のオイラーの等式まで届く。この章は背骨の最初の一段である。

**依存台帳**
- 〔前提〕2巻3章(相似条件・相似比) / 2巻4章(円・円周角の定理) / 2巻5章【自前】(多角形の面積) / 2巻6章(ピタゴラスの定理)
- 〔借用〕なし ── この章は前借りをしない
- 供給先: 4巻7章(三角関数)、2巻10章(幾何の武器庫)

一般角(90°を超える角、負の角)への拡張はこの章ではやらない。それは「回転」という新しい考え方が要る仕事で、4巻の三角関数に譲る。ここでは直角三角形の中だけで完結する世界を作る。

---

## 7.1　sin・cos・tan の定義(0°〜90°)

直角三角形をひとつ描く。直角でない角のひとつを θ とし、θ の対辺の長さを a、隣辺を b、斜辺を c とする。

ここで相似(3章)が効く。**角 θ が同じなら、直角三角形の大きさをどう変えても、辺の比は変わらない。** 二角相等(直角と θ)で相似だから、対応する辺の比は一定 ── これが3章で証明済みの事実だ。つまり比 a/c、b/c、a/b は、三角形の選び方によらず**角 θ だけで決まる**。角だけで決まるなら、角の関数として名前をつけてよい:

$$\sin\theta = \frac{a}{c},\qquad \cos\theta = \frac{b}{c},\qquad \tan\theta = \frac{a}{b}$$

定義から直ちに従う関係を確認しておく。まず $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$(分母分子を c で割るだけ)。次にピタゴラスの定理(6章)より a² + b² = c² だから、両辺を c² で割って

$$\sin^2\theta + \cos^2\theta = 1$$

また、直角三角形の残りの角は 90° − θ だから、対辺と隣辺が入れ替わって

$$\sin(90^\circ-\theta)=\cos\theta,\qquad \cos(90^\circ-\theta)=\sin\theta$$

co-sine(コサイン)の co は complement(余角)の co である。名前の中に、この入れ替わりが刻まれている。

ひとつ白状しておく。ここで θ は「度」で測っている。度とは何か ── 直角を90等分したもの、という規約だ。なぜ90か、そもそも角を「数で測る」とはどういうことか。この問いには実は深い答えがあり、5巻5章(弧長)で「角度とは弧の長さである」という再定義に出会う。いまは規約として受け入れて進む。

## 7.2　三角比の表、有名角の値

定義しただけでは道具にならない。値が要る。特別な直角三角形の比(6章3節)から、次の値が切り貼りなしで手に入る。

| θ | 30° | 45° | 60° |
|---|---|---|---|
| sin θ | 1/2 | √2/2 | √3/2 |
| cos θ | √3/2 | √2/2 | 1/2 |
| tan θ | √3/3 | 1 | √3 |

45° は直角二等辺三角形(1 : 1 : √2)から。30° と 60° は正三角形を半分に折った三角形(1 : 2 : √3)から。端の値も決めておく: θ が 0° に近づくと対辺は潰れて sin θ → 0、cos θ → 1。θ が 90° に近づくと sin θ → 1、cos θ → 0 で、tan θ は限りなく大きくなる(tan 90° は定義しない)。

有名角以外の値 ── sin 37° はいくつか ── は、この章の装備では「表を引く」が答えになる。歴史上も実際そうで、天文学者たちは膨大な三角比の表(正確には弦の表)を作った。表なしで任意の角の値を計算で出す方法は、マクローリン展開(5巻14章)を待つことになる。伏線として置いておく。

## 7.3　正弦定理

三角比は直角三角形の道具として生まれたが、実は**すべての**三角形を支配している。それを示すのが正弦定理と余弦定理という双璧だ。

**定理(正弦定理)** 三角形 ABC の各頂点の対辺を a, b, c、外接円の半径を R とすると

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

*証明の骨格。* 外接円(4章5節)を使う。頂点 B から円の中心を通る直径 BA′ を引くと、円周角の定理(4章)より角 A′ = 角 A(同じ弧 BC の上に立つ円周角)。しかも BA′ は直径だから、角 A′CB は半円の弧に立つ円周角で 90°。よって直角三角形 A′BC の中で sin A′ = a / 2R、すなわち a / sin A = 2R。他の辺も同様。∎

(角 A が 90° を超える場合は、この章の三角比の定義域からはみ出す。その場合の処理は円に内接する四角形の性質で回避できるが、本格的には4巻7章の一般角で解決する。ここでは鋭角三角形で話を確定させ、鈍角の場合は4巻への予告とする。)

直角三角形の中の比でしかなかった sin が、外接円という大道具と結びついた。「対辺と sin の比は、外接円の直径」── 定理の主張自体が、すでに少し不思議な景色をしている。

## 7.4　余弦定理

**定理(余弦定理)** 三角形 ABC で

$$a^2 = b^2 + c^2 - 2bc\cos A$$

*証明の骨格。* 頂点 B から辺 AC(またはその延長)に垂線 BH を下ろす。直角三角形 ABH の中で AH = c cos A、BH = c sin A。すると HC = b − c cos A だから、直角三角形 BHC にピタゴラスの定理(6章)を使って

$$a^2 = (c\sin A)^2 + (b - c\cos A)^2 = b^2 + c^2 - 2bc\cos A$$

(sin²A + cos²A = 1 を使った。) ∎

A = 90° なら cos A = 0 で、余弦定理はピタゴラスの定理そのものに退化する。つまり余弦定理は**ピタゴラスの定理の一般化**であり、補正項 −2bc cos A は「直角からのずれ」を測っている。6章で複数の証明を並べたあの定理は、ここで「すべての三角形の辺と角を結ぶ式」に育った。

正弦定理と余弦定理が揃うと、三角形は「絵に描いて測る」対象から「連立方程式を解く」対象に変わる。二辺夾角が与えられれば余弦定理で第三辺が出るし、一辺と二角なら正弦定理で残りが出る ── 合同条件(3章)のひとつひとつが、そのまま「解ける」ことの保証になっている。合同条件とは、実は「方程式の解が一意に定まる条件」だったのだ。

## 7.5　三角形の面積公式

**定理** 三角形 ABC の面積 S は

$$S = \frac{1}{2}bc\sin A$$

*証明。* 5章【自前】パートで、三角形の面積は(底辺)×(高さ)÷2 と確定している ── 切り貼りだけで、円は一切使わずに。底辺を b とすると、高さは頂点 B から下ろした垂線の長さで、直角三角形の中で c sin A に等しい。よって S = (1/2) b · c sin A。∎

依存関係にひとつ注意を書いておく(これはDAG検査で確定させた閉路回避条件だ)。この証明が使ってよいのは5章の**自前パート**(多角形の面積)だけであり、実際それしか使っていない。円の面積 πr²(5章の借用パート)にはここで触れない。触れると、πr² は5巻の積分に依存し、積分は三角関数の微分に、三角関数の微分はこの章の三角比に依存して ── 輪が閉じてしまう。三角比は「多角形の世界」だけを土台に立っている。この節の証明がその生きた証拠である。

## 7.6　コラム: エラトステネス ── 井戸と棒と三角比で地球の大きさを測る

紀元前3世紀、エラトステネスは地球の周長を測った。使ったのは、シエネの井戸(夏至の正午に太陽が真上に来て、井戸の底まで日が差す)と、アレクサンドリアに立てた棒と、その影だけだ。

夏至の正午、アレクサンドリアで棒とその影の長さを測ると、太陽光の傾きは約 7.2° ── 棒(高さ)と影(隣辺)の比、つまり tan からこの角が出る。太陽光は平行とみなせるから、錯角(2章)により、この 7.2° はシエネとアレクサンドリアが地球の中心に対して張る角に等しい。7.2° は 360° の 1/50。ゆえに地球の周長は二都市間の距離の50倍 ── 彼の見積もりは現代の値と1割前後しか違わなかったとされる。

道具立ては、この巻でここまでに揃えたものだけであることに注意してほしい。平行線と錯角(2章)、そして三角比(この章)。「直接測れないものを、測れるものの比から出す」── 三角比という道具の正体は、この一言に尽きる。4巻でこの道具は「波を記述する言語」に化けるのだが、それはまだ先の話。

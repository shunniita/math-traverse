## 4. 正準化された主張(量化つき)

- **T55B**: ∀x ∈ (0, π/2): sin x ≤ x ≤ tan x。(x = 弧長 = 弧度法の角。)
- **T55C**: ∀ε>0 ∃δ>0 ∀x (0<|x|<δ): |sin x/x − 1| < ε。
- **T411A**: ∀θ ∈ ℝ: e^{iθ} = cos θ + i sin θ。(e^{iθ} は 4-10 の級数の値。)
- **T411B**: e^{iπ} + 1 = 0。

## 11.1　複素指数関数とマクローリン展開の合流

装備を並べる。10章で建設した複素指数関数

$$e^z = \sum_{k=0}^{\infty}\frac{z^k}{k!}$$

(すべての複素数 z で絶対収束、指数法則つき)

と、5巻14章で保証された実関数の展開

$$\sin\theta = \theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \cdots,\qquad \cos\theta = 1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} - \cdots$$

そして i の性質はただひとつ、i² = −1(1巻)。これだけで頂上に届く。

## 11.2　オイラーの公式の導出

e^z の定義に z = iθ(θ は実数)を入力する:

$$e^{i\theta} = \sum_{k=0}^{\infty}\frac{(i\theta)^k}{k!} = 1 + i\theta + \frac{(i\theta)^2}{2!} + \frac{(i\theta)^3}{3!} + \frac{(i\theta)^4}{4!} + \cdots$$

i のべきは 1, i, −1, −i, 1, i, −1, −i, … と4周期で巡回する。項を実部(i のつかない項)と虚部(i のつく項)に仕分けする ── 無限和の項の並べ替えだが、この級数は絶対収束するから並べ替えは自由である(5巻6章。10章で点検済みの装備):

$$e^{i\theta} = \left(1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} - \cdots\right) + i\left(\theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \cdots\right)$$

括弧の中身を見よ。左は cos θ の、右は sin θ の展開式、そのものである。

**定理(オイラーの公式)** すべての実数 θ に対して
$$e^{i\theta} = \cos\theta + i\sin\theta$$

9章の観察 ──「exp の部品表から奇数次を抜くと sin、偶数次を抜くと cos、違いは符号の交代だけ」── の答え合わせがこれだ。符号の交代の正体は i² = −1 だった。爆発する関数と揺れる関数は、複素数平面では同じ一つの関数であり、実軸方向に眺めれば爆発(eˣ)、虚軸方向に眺めれば回転と振動(cos + i sin)に見えていただけである。

幾何の言葉にも翻訳しておく。|e^{iθ}| = √(cos²θ + sin²θ) = 1 ── e^{iθ} は**単位円上の、偏角 θ の点**である(3巻6章の複素数平面がここで効く)。すると指数法則 e^{iα}e^{iβ} = e^{i(α+β)} は「偏角は掛け算で足される」つまり**回転の合成**を意味し、実部・虚部を比べればそれは加法定理(7章)そのものである。ド・モアブルの定理 (cos θ + i sin θ)ⁿ = cos nθ + i sin nθ も (e^{iθ})ⁿ = e^{inθ} と書けば指数法則の一行になる。3巻と7章で別々に育てた道具たちが、一本の式に畳み込まれた。

## 11.3　オイラーの等式: 5つの定数の出会い

オイラーの公式に θ = π を入れる。ここで π とは何だったか ── 単位円の半円弧の長さである(5巻5章)。同章で構成した弧長パラメータ表示 P により、点 (cos π, sin π) = P(π) は、(1, 0) から弧に沿って**ちょうど半周**だけ進んだ点。すなわち (−1, 0)。ゆえに cos π = −1、sin π = 0。よって

$$e^{i\pi} = -1,\qquad e^{i\pi} + 1 = 0$$

この一行に、本書の主役五人が全員いる。

- **0** ── 0巻。空集合から作った、最初の数。
- **1** ── 0巻。後者関数が最初に生んだ数。1+1=2 の主語。
- **i** ── 1巻。三次方程式の実数解を救うために、渋々と認められた数。
- **π** ── 5巻5章。内接折れ線の sup として、完備性に支えられて生まれた弧の長さ。
- **e** ── 5巻9章。複利の極限として生まれ、微分で不動の関数 eˣ の底。

出自も巻もばらばらの五人が、足し算(0巻)・掛け算(0巻)・指数(4巻5章→10章)という基本演算だけで、一つの短い真実を作る。そして思い出してほしい ── この式は1巻の山場で「予告編」として一度掲げられた。あのとき読者は五人の誰もまともに知らなかった。いま、五人全員の戸籍と、式が成り立つ理由の全証明が手元にある。予告編から本編まで、飛ばした段は一段もない。

## 11.4　ガウスの言葉の意味を、今こそ

「この式を示されて直ちに明らかだと思えないなら、その学生は第一級の数学者にはなれないだろう」── オイラーの等式についてガウスが言ったと**伝えられる**言葉である(直接の典拠は確認されておらず、伝聞として広まった言葉であることは正直に記しておく。出典の怪しい引用に借用証書を貼るのも本書の流儀だ)。

真贋はさておき、この言葉が指す内容はいま検証できる。「直ちに明らか」とは、天才には証明が不要という意味ではない。e^{iθ} が単位円上の回転だと**見えて**いれば、e^{iπ} = −1 は「半回転すれば反対側に着く」という、ただの地理の話になる ── そう見えるかどうかを問うている。11.2の景色(exp は虚軸方向には回転である)を手に入れた読者にとって、この式はもう神秘ではない。半周回れば −1 に着く。それだけのことが、それだけのこととして見えるようになるために、9巻ぶんの装備が要ったのである。神秘が消えたあとに残るのは落胆ではなく、見晴らしだ。

## 11.5　親戚関係の開示: 双曲線関数の正体(5章の伏線回収)

5章4節で、e から作った双曲線関数

$$\cosh x = \frac{e^x + e^{-x}}{2},\qquad \sinh x = \frac{e^x - e^{-x}}{2}$$

が三角関数に**そっくり**(cosh² − sinh² = 1、加法定理も同形)なのはなぜか、という宿題を出した。オイラーの公式から、実数 θ に対して cos θ = (e^{iθ} + e^{−iθ})/2、sin θ = (e^{iθ} − e^{−iθ})/(2i) と逆に解ける。そこで cos と sin を、10章の e^z と同じ作法で複素数の引数へ拡張する:

$$\cos z = \sum_{k=0}^{\infty}\frac{(-1)^k z^{2k}}{(2k)!},\qquad \sin z = \sum_{k=0}^{\infty}\frac{(-1)^k z^{2k+1}}{(2k+1)!}$$

(収束は各項の絶対値を e^{|z|} の級数と比べればよく、10章の点検1と同型。実数では5巻14章の展開と一致するから、拡張であって改変ではない。) この定義の下で、e^{iz} と e^{−iz} を級数のまま足すと奇数次の項が相殺して cos z の級数の2倍が残る ── 収束級数の項別の加減はつねに正当であり、項の仕分けは絶対収束(5巻6章)が許す。すなわち cos z = (e^{iz} + e^{−iz})/2、sin z = (e^{iz} − e^{−iz})/(2i) は、実数に限らず**すべての複素数 z** で成り立つ。z = ix を入れて

$$\cos(ix) = \cosh x,\qquad \sin(ix) = i\sinh x$$

そっくりなのではない。**同一人物の、実軸方向の顔と虚軸方向の顔**である。単位円 cos² + sin² = 1 と双曲線 cosh² − sinh² = 1 は、複素数平面ではひとつの曲面の二つの切り口にすぎない。三角関数(円関数)と双曲線関数という命名の対称性は、こうして初めて正当化される。宿題、回収完了。

## 11.6　コラム: もう一つの世界線 ── sin・cos をべき級数で定義する流儀

現代の解析学の教科書には、本書と逆向きの構成がある。**最初に** sin x := x − x³/3! + …、cos x := 1 − x²/2! + … と定義してしまい、π は「cos の最小の正の零点の2倍」として定義する流儀だ。

この世界線では、循環論法は発生する余地すらない。弧長も面積も要らず、lim sin x/x = 1 は定義から一行で出る。論理的には完璧に美しい ── そして、物語が死ぬ。その定義を初めて見た読者には、sin が三角形とも円とも関係する理由が消え、πが円周率である理由は証明すべき定理に格下げされる。答えを最初に書いた推理小説である。

本書が弧長ルートを正典に選んだのは、弧長ルートだけが「小学校で円を習った読者が、いま持っている π のイメージ」を一度も没収せずに頂上まで運べるからだ。ただし、べき級数ルートの存在は知っておく価値がある。11.2 でわれわれは e^z をべき級数で**定義**した ── つまり本書も、複素数の領域では既にあちらの世界線の作法を採用している。二つの世界線は矛盾しない。同じ山に、麓の違う登山道が二本あるだけである。

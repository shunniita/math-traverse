# 4巻 7章　三角関数: 円から生まれる波

**背骨ノード** ── 2巻の三角比(直角三角形の中の比、0°〜90°)を、単位円ですべての実数へ拡張する。ここで三角関数は「三角形の道具」から「周期現象を記述する言語」へと生まれ変わる。

## 7.1　単位円による一般角への拡張

2巻の三角比は直角三角形に閉じ込められていた。角は 0° から 90° まで ── 三角形の中の角だから当然だ。だが正弦定理はすでに鈍角ではみ出しかけていたし、回転や波を扱うには 360° も、その先も、逆回りも要る。

拡張の舞台は単位円である。原点 O を中心とする半径1の円の上で、点 (1, 0) から角 θ だけ回転した点を P とする。反時計回りを正、時計回りを負と約束する。そして

P の座標を使って、cos θ を P の x 座標、sin θ を P の y 座標と**定義し直し**、

$$\tan\theta = \frac{\sin\theta}{\cos\theta}\qquad (\cos\theta\neq 0)$$

とする。0° < θ < 90° では、P から x 軸に垂線を下ろせば2巻の直角三角形が現れ、旧定義と一致する ── 拡張であって改変ではない。だが新定義は θ = 200° でも −90° でも 1000° でも平気で動く。座標は符号を持つから、sin と cos は象限に応じて負にもなる。定義から直ちに、任意の θ で

$$\sin^2\theta + \cos^2\theta = 1$$

(P が単位円上にいる、というただそれだけのこと。ピタゴラスの定理が「円の方程式」に化けた ── 3巻の景色である。)

## 7.2　弧度法 ── 角度=弧長という定義 〔借用: 5巻5章〕

ここからは角を「度」ではなく**弧の長さ**で測る。角 θ の大きさとは、単位円からその角が切り取る弧の長さのこと。一周は 2π、平角は π、直角は π/2 である。

**〔借用証書〕** 「弧の長さ」なるものが存在してひとつに定まること ── 曲線の長さの定義(内接折れ線の長さの sup)と、その sup の存在(実数の完備性) ── は、5巻5章で厳密に構成される。本章はその結果だけを前借りする。回収先: 5巻5章1〜4節。

なぜ度を捨てるのか。度は「直角の90等分」という人間の規約だが、弧長は円そのものが持っている量であり、規約が入り込まない。そして実利がある: 角の単位を弧長に揃えたときに限り、lim sin x/x = 1 (5巻5章)が成り立ち、微分公式 (sin x)′ = cos x が余計な定数なしの美しい形になる(5巻8章)。度のまま微分すると π/180 が全公式にまとわりつく。弧度法は趣味ではなく、解析学の生存条件である。

## 7.3　三角関数のグラフ、周期性

θ を横軸、sin θ を縦軸に取ると、波が現れる。P が円を一周すると値は完全に元に戻るから

$$\sin(\theta + 2\pi) = \sin\theta,\qquad \cos(\theta + 2\pi) = \cos\theta$$

── 周期 2π の**周期関数**である。tan は半周期で戻る(周期 π)。円運動を横から眺めた影が波、というこの対応が、三角関数が波動・振動・音・光のいたるところに現れる理由のすべてだ。

グラフからも単位円からも読める基本対称性を並べておく: sin は奇関数(sin(−θ) = −sin θ)、cos は偶関数。cos θ = sin(θ + π/2)、つまり cos は sin を平行移動しただけの同族(1章のグラフ移動の実戦)。

## 7.4　加法定理

一般角の三角関数の最初の本格的な定理であり、この先(2倍角・合成・そして11章)のすべての親になる。

**定理(加法定理)**
$$\cos(\alpha-\beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$$
$$\sin(\alpha+\beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta,\qquad \cos(\alpha+\beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$$

*証明の骨格。* 単位円上の2点 A = (cos α, sin α)、B = (cos β, sin β) の距離を、2点間の距離公式(3巻)で2通りに測る。ひとつは座標のまま展開する。もうひとつは、2点を角 −β だけ回転させても距離は変わらないことを使う ── 回転後は A′ = (cos(α−β), sin(α−β))、B′ = (1, 0) となり、距離が簡単に書ける。両者を等しいと置いて整理すると cos(α−β) の式が出る。残りは β → −β の置き換えと、cos θ = sin(θ + π/2) の付け替えで機械的に従う。∎

証明に使ったのは距離公式と「回転は距離を変えない」だけ ── 微分も極限も面積も使っていない。この定理は5巻5章より**前**の装備で成り立つ純幾何の定理であり、だから5巻8章が三角関数の微分を作るとき、安心してこの定理を使える(sin(x+h) を開くのに加法定理が要る)。

## 7.5　2倍角・半角の公式

加法定理で α = β と置くだけで

$$\sin 2\alpha = 2\sin\alpha\cos\alpha,\qquad \cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 1 - 2\sin^2\alpha = 2\cos^2\alpha - 1$$

cos 2α の式を逆に解けば半角の公式 sin²α = (1 − cos 2α)/2、cos²α = (1 + cos 2α)/2。「2乗を1次に下げる」このかたちは、5巻の積分(∫sin²x dx)で主力になる。公式は暗記の対象ではなく、加法定理から30秒で再生産できる派生物である ── という体験をここでしておくと、この先の人生が楽になる。

## 7.6　三角関数の合成

$$a\sin\theta + b\cos\theta = \sqrt{a^2+b^2}\,\sin(\theta+\varphi)\qquad \left(\cos\varphi = \tfrac{a}{\sqrt{a^2+b^2}},\ \sin\varphi = \tfrac{b}{\sqrt{a^2+b^2}}\right)$$

証明は右辺を加法定理で開いて係数を比べるだけ。意味のほうが大事だ: **同じ周期の波は、何個足しても一つの波にしかならない**(振幅と位相が変わるだけ)。点 (a, b) の偏角として φ を読む見方は3巻(座標)の直系で、11章で複素数平面と合流する。

## 7.7　三角方程式・不等式

sin θ = 1/2 を解く。単位円の y 座標が 1/2 になる点は(一周の中に)2つあり、θ = π/6, 5π/6。周期性により、一般解は θ = π/6 + 2nπ, 5π/6 + 2nπ (n は整数)。方程式を解く作業は「単位円の上で点を探し、周期の分だけ増殖させる」に尽きる。不等式 sin θ > 1/2 も同様に、円周上の弧として答えが読める。グラフで解いても円で解いてもよい ── 同じものを横から見るか上から見るかの違いである。

## 7.8　残りの三兄弟: sec・cosec・cot

$$\sec\theta = \frac{1}{\cos\theta},\qquad \operatorname{cosec}\theta = \frac{1}{\sin\theta},\qquad \cot\theta = \frac{1}{\tan\theta}$$

sin²+cos²=1 を cos² で割れば 1 + tan²θ = sec²θ、sin² で割れば 1 + cot²θ = cosec²θ。この2本は5巻の積分(置換 t = tan θ など)で頻繁に顔を出す。日本の高校教科書からこの三人が姿を消したのは戦後のカリキュラム簡素化によるもので、数学的な理由ではない ── 英語圏の教科書では現役なので、洋書を読むなら初対面のふりをしないこと。

## 7.9　逆三角関数: arcsin・arccos・arctan

「sin θ = 1/2 となる θ」を関数として扱いたい。だが sin は周期関数、同じ値を無限回とるから、そのままでは逆関数を持たない(4章: 逆関数には単射が要る)。処方箋は4章で確立済み ── **単調な区間に切り出す**。

- sin を [−π/2, π/2] に制限 → 逆関数 **arcsin**: [−1, 1] → [−π/2, π/2]
- cos を [0, π] に制限 → **arccos**: [−1, 1] → [0, π]
- tan を (−π/2, π/2) に制限 → **arctan**: ℝ → (−π/2, π/2)

どの区間に切り出すかは規約だが、上記が世界標準である。予告をひとつ: これらを微分すると 1/√(1−x²) や 1/(1+x²) という、三角関数の気配のない有理式・無理式が現れる(5巻8章)。おかげで ∫dx/(1+x²) = arctan x + C ── 積分の世界では、逆三角関数は主役級の働き手になる。

# 8巻 8章　圏論への扉(ほんの入口だけ)

群、環、体、ベクトル空間、順序集合、位相空間。この巻と前の巻で、「構造」をいくつも見た。それぞれに「構造を保つ写像」(準同型・線形写像・単調写像・連続写像)があり、「同型」があり、「潰した分で割る」定理があった。同じ型の議論が繰り返されるなら、その型自体を対象にできないか。それが圏論である。この章は扉を開けて中を覗くだけで、中には入らない。

**依存台帳**
- 〔前提〕0巻2章(写像・合成・全単射) / 本巻1〜7章(群・環・体と準同型) / 7巻(線形写像) / 5巻4章(連続写像)
- 〔借用〕なし。この章は全体が遠望
- 供給先: EX巻(数学の見方の一つとして)、9巻(型と関数の圏、モナド)

## 8.1　対象と射

**定義(概略)** **圏**とは、**対象**の集まりと、対象の間の**射**の集まりで、射の合成が定義され、結合法則と恒等射の存在を満たすものをいう。

| 圏 | 対象 | 射 |
|---|---|---|
| **Set** | 集合 | 写像 |
| **Grp** | 群 | 群準同型 |
| **Ring** | 環 | 環準同型 |
| **Vect**$_K$ | $K$ ベクトル空間 | 線形写像 |
| **Top** | 位相空間 | 連続写像 |
| 一つの群 $G$ | 一点 | $G$ の元(合成は積) |
| 順序集合 | 元 | $a\le b$ のとき射 $a\to b$ が一つ |

最後の二行に注意してほしい。群は「対象が一つで、すべての射が可逆な圏」であり、順序集合は「どの二対象の間にも射が高々一つの圏」である。圏は、構造の集まりであると同時に、構造そのものでもある。

**射だけを見る。** 圏論の流儀は、対象の「中身」を見ず、射の「つながり方」だけで語ることである。単射は「左から消去できる射」(モノ射)、全射は「右から消去できる射」(エピ射)、同型は「逆射を持つ射」、と定義し直す。中身(元)を使わないので、集合でない対象にも同じ言葉が通用する。

**普遍性。** 「直積」を、元の組としてではなく、射の性質で定義する: $A\times B$ とは、射 $p_1:A\times B\to A$、$p_2:A\times B\to B$ を持ち、任意の対象 $X$ からの射の組 $(X\to A,X\to B)$ が、ただ一つの射 $X\to A\times B$ を経由して得られるような対象である。この定義は Set では直積集合、Grp では直積群、Vect では直和を与える。「同じ定義が、圏を替えると別の構成を出す」── これが圏論が「型そのものを対象にする」の意味である。0巻1章の直積、7巻の直和は、一つの普遍性の二つの顔だった。

## 8.2　関手の雰囲気

圏から圏への「構造を保つ写像」を**関手**という。対象を対象に、射を射に写し、合成と恒等射を保つ。

- **忘却関手** Grp → Set: 群を、演算を忘れて集合と見る。
- **自由関手** Set → Grp: 集合から、その元を生成元とする群(自由群)を作る。忘却関手の「逆」に最も近いもの(随伴、遠望)。
- **基本群** Top → Grp: 空間に「輪の群」を対応させる。2巻11章のオイラー標数も、空間から整数への「関手的な」対応で、連続写像で保たれることが、位相不変量である理由である。
- **双対** Vect → Vect: $V\mapsto V^*$。射の向きが逆になる(反変関手)。

関手の間の「写像」が**自然変換**で、これが圏論の本来の出発点だった(アイレンバーグ・マックレーン、1945年)。「自然な同型」という数学者の口癖(「$V$ と $V^{**}$ は自然に同型だが、$V$ と $V^*$ は自然でない」)を定義するために、関手と圏が発明された。7巻で「基底を選ばずに成り立つ同型」と述べたものが、自然変換の言葉で正確になる。

## 8.3　これまで見た構造を圏論の言葉で振り返る

- **同値類で数を作る**(1巻7〜8章、3巻4章): 商集合 $X/{\sim}$ は、「$\sim$ で同一視される元を同じ行き先に送る射」についての普遍性で特徴づけられる。分数、整数、ベクトルの構成は、すべて同じ普遍性の実例である。
- **準同型定理**(本巻2章コラムの表): 「潰した分で割れば届いた先と同じ」は、任意の圏で「像分解」として述べられる。
- **自然数**(0巻4章): $(\mathbb{N},0,S)$ は「点つき自己写像」の圏の始対象である。原始再帰の原理は、始対象からの射がただ一つ存在することの言い換えであり、0巻4章6節の「同型を除いて一つ」は始対象の一意性そのものである。
- **実数**(1巻9章): 完備順序体は、順序体の圏で「終対象」に近い位置にあり、同型を除いて一つ。
- **ガロア対応**(本巻7章): 部分群の順序集合と中間体の順序集合の間の、向きを逆にする同値。「対応」と呼ばれるものの多くが、圏の同値または随伴である。
- **プログラム**(9巻): 型を対象、関数を射とする圏で、関数型プログラミングの「関手」「モナド」は文字どおり圏論の概念である。

圏論は、この本で繰り返し現れた「同じ型の議論」に名前をつける言語である。それ自体が定理を証明するわけではないが、「なぜ同じ議論が通用するのか」に対する、最も一般的な答えを与える。

## 4.1　関数の極限: ε-δ論法

3章で数列の極限を ε-N で厳密化した。「どんな誤差 ε を要求されても、番号 N から先は全部誤差内」。関数でも同じことをしたい。x が a に近づくとき f(x) が L に近づく、の「近づく」を、動く点のアニメーションなしで言い切りたい。

数列との違いは一点だけだ。数列は「番号 N から先」で近さを指定したが、関数では「a からの距離 δ 以内」で指定する:

$f:D\subset\mathbb{R}\to\mathbb{R}$ とし、a を D の集積点とする。

**定義** $\lim_{x\to a} f(x) = L$ とは、任意の ε > 0 に対して δ > 0 が存在し、$x\in D$ かつ 0 < |x − a| < δ ならば |f(x) − L| < ε となること。

ε-N の N を δ に置き換えただけ ── 挑戦者が誤差 ε を突きつけ、応戦者が範囲 δ で応じるゲームの構図はそのままだ。条件に 0 < |x − a| が入っている(x = a 自身は見ない)ことには意味がある。f(a) の値がどうであろうと、極限は「周りからどう見えるか」だけで決まる。次章で lim sin x/x を扱うとき、x = 0 で定義されていない関数の極限を平気で語れるのは、この一句のおかげである。

δ を実際に選ぶところまで見ておこう。$f(x)=2x+1$ なら、a のまわりで

$$|f(x)-f(a)|=2|x-a|$$

だから、要求された ε に対して δ = ε/2 と選べばよい。定義は記号の飾りではなく、「ε を渡されたら δ を返す」手続きである。

極限の性質(和・積・商の極限、はさみうち)は、3章の数列版とまったく同じ形で成り立つ。実際、次の橋渡しが成り立つ:

**補題(数列による言い換え)** $\lim_{x\to a} f(x) = L$ であることと、a に収束するどんな数列 $x_n\in D\setminus\{a\}$ についても f(xₙ) → L となることは同値。

この補題を使えば、3章で証明済みの数列の定理を関数の世界へ運べる。ただし商なら分母が0に近づかないことなど、それぞれの定理の仮定は引き継がなければならない。

## 4.2　連続性の定義 ── 4巻への借用証書を回収する

**定義** $a\in D$ とする。f が点 a で**連続**とは、D の中から x → a としたとき $\lim_{x\to a} f(x) = f(a)$ となること。区間のすべての点で連続なら、f はその区間で連続という。区間の端点では、その区間の内側から近づく極限を使う。

「極限値が存在して、しかもそれが f(a) に一致する」── グラフが a のところで切れても跳んでもいない、ということの正式な言い分だ。

ここで借用証書を一枚回収する。4巻8章で、コーシーの関数方程式 f(x+y) = f(x) + f(y) の解は「連続性を仮定すれば」f(x) = cx に限る、と述べた。あのときの「連続性」は未定義の借り物だった。いま定義が与えられたので、あの主張は正式な定理になった(証明の完成はこの節の演習とする: 有理数点では加法性だけで f(q) = cq が出て、無理数点へは連続性で橋を架ける ── 有理数の稠密性(1巻)が効く)。

連続関数を一つずつ ε-δ で作り直す必要はない。定数関数と恒等関数は連続であり、連続関数の和・積・合成も連続である。商は分母が0でない点で連続だ。したがって多項式は全実数で連続になる。

$\sqrt{x}$ も $[0,\infty)$ で連続である。a > 0 なら

$$|\sqrt{x}-\sqrt{a}|=\frac{|x-a|}{\sqrt{x}+\sqrt{a}}$$

で押さえられ、a = 0 では $|\sqrt{x}|<\varepsilon$ を得るために $0\le x<\varepsilon^2$ とすればよい。次章で $\sqrt{1-t^2}$ の連続性を使えるのは、この準備があるからだ。log の連続性は、指数関数の連続性と狭義単調性から、逆関数についての結果を使って別途確かめる。9章ではその結果を使う。

## 4.3　連続関数は極限を「通す」

連続性の定義を数列の言葉(4.1の補題)で言い直すと、こうなる:

$$x_n \to a \ \Longrightarrow\ f(x_n) \to f(a),\qquad \lim_{n\to\infty} f(x_n) = f\left(\lim_{n\to\infty} x_n\right)$$

**連続関数 f については、$\lim f(x_n)=f(\lim x_n)$ という形で極限と f の適用順を交換できる。** 地味に見えて、これは本書後半で何度も無言で使われる操作の免許証だ。たとえば9章で e を導出するとき、lim(1 + 1/n)ⁿ の対数を取る一手が合法なのは、log が連続だからである。免許のない lim と関数の交換は事故のもとで、どんな事故が起きうるかは14章(関数列の収束)で詳しく扱う。

## 4.4　中間値の定理

**定理(中間値の定理)** f が閉区間 [a, b] で連続で、f(a) < 0 < f(b) ならば、f(c) = 0 となる c が (a, b) に存在する。(一般の中間値 k についても、f − k を考えれば同じ。)

*証明の骨格。* 完備性(1巻9章)を区間縮小の形で使う。[a, b] を半分に割り、中点での符号を見て「符号が変わる側」の半区間を選ぶ。これを繰り返すと、長さが半分ずつ潰れていく閉区間の入れ子ができる。完備性により、すべての区間に共通する点 c がただひとつ存在する。

c で f(c) > 0 とすると、連続性より c の近くでは f > 0 のはずだが、c に潰れていく各区間は左端で f ≤ 0 の点を含むから矛盾する。f(c) < 0 も同様に矛盾する。よって f(c) = 0。∎

グラフが下から上へ行くなら、どこかで必ず軸を横切る ── 主張は見れば当たり前に思える。だが証明が完備性を要求していることに注意してほしい。有理数の世界では、この定理は**嘘**になる。f(x) = x² − 2 は f(1) < 0 < f(2) だが、有理数の範囲に根はない(√2 の無理性、1巻)。「当たり前」を支えていたのは、実数に隙間がないという、1巻9章で正面から購入したあの性質である。

次章では、この定理と完備性が「円弧の長さ」の存在を保証する場面に立ち会うことになる。

## 4.5　最大値・最小値の定理

**定理(最大値・最小値の定理)** f が閉区間 [a, b] で連続ならば、f は [a, b] 上で最大値と最小値をとる。

*証明の骨格。* まず有界性を示す。有界でないとすると |f(xₙ)| > n となる点列がとれる。[a, b] は有界だから、3章の単調部分列の議論(ボルツァーノ=ワイエルシュトラス: 有界数列は収束部分列を持つ ── 完備性の子ども)により収束部分列 $x_{n_k}\to c\in[a,b]$ がとれる。ところが連続性より $f(x_{n_k})\to f(c)$ で有限だから、発散と矛盾する。

次に $M=\sup_{x\in[a,b]}f(x)$ とし、$f(x_n)\to M$ なる点列に同じ議論を使う。ある部分列が c に収束し、その極限点で f(c) = M となる。sup が max に昇格した。最小値は −f に同じ議論を適用すればよい。∎

「閉」区間であることは外せない。開区間 (0, 1) 上の f(x) = x は連続で、sup は1だが最大値を持たない。端が開いていると、値は sup に向かって逃げ続けられる。閉じた区間は逃げ場を塞ぐ。

この定理は7章でロルの定理・平均値の定理の土台になり、そこから微分法の全体が立ち上がる。地味な章だったが、これで足場は組み上がった。次章、いよいよ本書の隠れた要石 ── 弧長とπ ── に登る。

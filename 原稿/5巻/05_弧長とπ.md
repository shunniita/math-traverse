## 5.1　曲線の長さをどう定義するか: 内接折れ線の supremum

まっすぐな線分の長さは測れる(2巻)。では曲がった線の長さとは何か。定規は曲がらないのだから、これは定義しなければ始まらない問いである。

素直な発想はこうだ。曲線の上に点を何個か打ち、順に線分で結ぶ ── **内接折れ線**である。折れ線の長さなら測れる。点を増やして折れ線を細かくすれば、折れ線は曲線に沿っていき、長さは増える。実際、点をひとつ追加すると、一本の線分が二本の折れ線に置き換わり、三角不等式(2巻)により長さは減らない。つまり**細分するほど折れ線の長さは単調に増える**。

増え続ける量の「行き先」を捕まえる道具を、我々はすでに持っている。上限(sup)だ(3章5節)。

**定義** 曲線 C の**長さ**とは、C の内接折れ線の長さ全体の集合の上限(sup)である。上限が有限のとき C は**長さを持つ**という。

「極限」ではなく「上限」で定義することに注意。折れ線の取り方は無数にあり、点の増やし方の列を特定せずに済むのが sup の利点だ。ただし sup は、集合が上に有界なときにしか存在しない(1巻9章)。内接折れ線の長さは、際限なく大きくなってしまわないか? ── 円については、ならない。それを次節で保証する。

定義の輪郭をひとつ絞っておく。本章で「曲線」と呼ぶのは端点つきの**円弧**だけであり、内接折れ線は弧の上の並び順に点を結ぶ。一般の曲線の長さの理論は、要るようになってから作る(要らないのに作らない ── 作れない曲線もいることは章末のコラム候補で)。

## 5.2　完備性が保証してくれること

鍵になるのは、面積とは無関係の、周の長さだけの補題である。

**補題1(折れ線の三角不等式)** 同じ2点を結ぶ折れ線は、線分より短くない。
*証明。* 折れ線の頂点数についての帰納法。頂点をひとつ飛ばして結ぶと、三角不等式(2巻)により長さは減るか変わらない。繰り返せば線分に至る。∎

**補題2(凸多角形の周長単調性)** 凸多角形 K が凸多角形 L に含まれるなら、K の周長は L の周長以下。
*証明。* K の辺をひとつ選び、それを含む直線で L を切り、K を含む側だけを残す。この操作で L の境界は「折れ線の一部」が「一本の線分」に置き換わるから、補題1により周長は減るか変わらない。K のすべての辺の直線で順に切ると、残る図形は K 自身。よって周長(K) ≤ 周長(L)。∎

面積を使いそうな場面の筆頭「内側の図形は周も短い」が、切って比べるだけで証明できた。これで円弧の内接折れ線を、外から押さえられる。

**定理** 単位円(半径1の円)の弧は長さを持つ。
*証明。* 弧の内接折れ線に、中心 O と弧の両端を結ぶ2本の半径を付け足すと、凸多角形 K ができる(中心角が π 未満なら、O と弧上の点を順に結んだ多角形は各頂点での内角が π 未満になるので凸 ── 2巻。長い弧は半円未満の弧に分割すればよい)。一方、円に外接する正方形と O を結んでできる図形など、K を含む凸多角形 L はいくらでも取れる。補題2より 周長(K) ≤ 周長(L)。半径2本の長さ(=2)を差し引けば、折れ線の長さは 周長(L) − 2 以下 ── 上に有界である。よって完備性(1巻9章)により sup が存在する。∎

実数の完備性が、ここで初めて「目に見える仕事」をした。有理数の世界には √2 がなかったように、完備性のない世界には「円弧の長さ」という実数が存在しない。1+1=2 から積み上げてきた実数論は、この一点のためにあったと言ってよい。

なお弧長について、以後断りなく使う性質を3つ挙げておく。**加法性**: 弧を2つに分ければ、長さの和は元の弧の長さ(内接折れ線の分割点に共通点を挟んで sup を取り直すだけ)。**狭義単調性**: 端点の片方を弧に沿って動かすと、長さは狭義に増える(加法性と、弧の長さ ≥ 弦の長さ > 0)。**合同不変性**: 合同な弧は同じ長さを持つ(合同変換は各線分の長さを変えないから、内接折れ線の長さの集合そのものが一致する)。

もうひとつ、外側から押さえる評価を補題の形で切り出しておく。次節の主役でもあり、弧長の「連続性」の担保でもある。

**補題3(接線による外側からの評価)** 四分円以下の弧の長さは、弧の両端それぞれでの接線の交点 T を経由する折れ線(2本の接線線分)の長さ以下である。
*証明。* 弧の任意の内接折れ線に、中心 O と弧の両端を結ぶ半径2本を付け足した凸多角形 K は、半径2本と接線線分2本で囲まれる凸四角形に含まれる(円は接線の内側にあるから)。補題2で周長を比べ、両辺から半径2本ぶんを引くと、内接折れ線 ≤ 接線折れ線。sup を取って弧長 ≤ 接線折れ線。∎

**系(弧長は弦の√2倍以下)** 四分円以下の弧で、中心角の半分を φ (0 < φ ≤ π/4) とすると、直角三角形の三角比(2巻 ── 本章で作る解析的な sin・cos とは独立)により、弦 = 2 sin φ、接線折れ線 = 2 tan φ = 弦 / cos φ。φ ≤ π/4 では cos φ ≥ √2/2 だから、**弧長 ≤ 接線折れ線 ≤ √2 × 弦**。とくに弦を 0 に近づけると弧長も 0 に近づく ── 弧長は端点の位置について連続である。

## 5.3　πの定義: 単位円の半円弧の長さ

**定義** $\pi$ とは、単位円の半円弧の長さである。

これが本書における π の定義だ。「円周率 = 円周 ÷ 直径」という小学校の言い方とは、半径1で円周 = 2π となることで一致する。この瞬間まで、本書に π は登場していない(1巻で名前だけ予告した)。円の面積 πr² は、まだ**何も**主張していないことに注意 ── あれは11章で積分により証明される定理であって、πの定義とは別物である。

値の見当をつけておこう。単位円に内接する正六角形は、一辺1(中心角60°の二等辺三角形が正三角形になる ── 2巻)。半円分は3辺だから、内接折れ線として 3 ≤ π。頂点をひとつ追加すれば折れ線は狭義三角不等式で真に長くなるから、実は 3 < π。外側は、外接正方形の半分と補題2を比べて π ≤ 4、角を落とした外接八角形の半分と比べれば π < 4。あわせて 3 < π < 4。アルキメデスはこの挟み撃ちを正96角形まで進めて 3 + 10/71 < π < 3 + 1/7 を得た ── 使った道具は、いま我々が組んだものと本質的に同じである。

## 5.4　角度の再定義: 弧度法は定義そのものだった

2巻からずっと、角は「度」で測ってきた。直角を90等分するという規約 ── バビロニア以来の伝統だが、数学的必然性はない。いま、必然性のある測り方が手に入った。

**定義(弧度法)** 角の大きさとは、その角を中心角として単位円から切り取られる**弧の長さ**である。

平角(180°)は半円弧を切り取るから π。直角は π/2。一周は 2π。「180° = π ラジアン」という換算公式を暗記するのではない ── 角度とは弧長のことだ、というのが定義である。

ここで4巻7章2節への借用証書を回収する。4巻は三角関数を一般角へ拡張する際「弧度法 ── 厳密な弧長は5巻で」と前借りしていた。その担保がこの節である。

以後、実数 x (0 ≤ x ≤ π/2) に対して、単位円上で点 A = (1, 0) から弧に沿って反時計回りに長さ x だけ進んだ点を P(x) と書く。この点がちょうど一つ存在することを確かめる。四分円(第一象限)を x 座標でパラメータ付けし、t ∈ [0, 1] の点 (t, √(1−t²)) に対して A からの弧長を s(t) とする。s は狭義単調(弧長の狭義単調性)。連続でもある: |s(t) − s(t′)| は、加法性により点 (t, √(1−t²)) と (t′, √(1−t′²)) の間の部分弧の長さであり、t′ → t のときその弦は(√(1−t²) の連続性により)0 に潰れるから、補題3の系より部分弧の長さも 0 に潰れる。そして s(1) = 0。もう一方の端は s(0) = 四分円弧の長さ = π/2 ── 半円は y 軸鏡映で互いに合同な四分円2つに割れるから、合同不変性と加法性で半分ずつ、である。よって中間値の定理(4章)により、各 x ∈ [0, π/2] に対して P(x) がちょうど一つ定まる。そして **cos x を P(x) の x 座標、sin x を P(x) の y 座標と定義する**。

定義域はこのままでは [0, π/2] で止まっている。残りの円周へは対称性で延ばす。まず x ∈ [0, π/2] に対して P(π − x) を P(x) の y 軸鏡映と**定義**して [0, π] を埋め、次に x ∈ [0, π] に対して P(π + x) を P(x) の原点対称と定義して [0, 2π] を埋める(境界 x = π/2、π での重複定義は同じ点を与える)。負の x には P(−x) の x 軸鏡映、以後は 2π 周期で全実数へ ── 周期規則と鏡映規則の重なりも同じ点を与える。弧長は合同変換で不変だから、こうして延ばした P は全実数の弧長パラメータ表示(進んだ弧長のぶんだけ点が円周上を回る対応)であり、貼り合わせの整合は合同不変性と加法性が保証する。sin が奇関数で cos が偶関数であること、周期が 2π であることは、この定義から直ちに従う。一般角の三角関数(4巻7章)への供給は、この段落が担保である。角 ∠AOP の(弧度法での)大きさは x だから、直角三角形の比としての2巻の三角比と、この定義は一致する。三角比(2巻)は「角の関数」だったが、いま角そのものが実数(弧長)になったので、sin と cos は晴れて**実数の関数**になった。解析学の土俵に乗ったのである。

## 5.5　弦は弧より短く、弧は外接折れ線より短い: sin x ≤ x ≤ tan x を面積なしで

教科書はこの不等式を扇形の面積で示す。我々は長さだけで示す。0 < x < π/2 とし、O を中心、A = (1,0)、P = P(x) とする。

**左側: sin x ≤ x。**
P から線分 OA に下ろした垂線の足を H とすると、PH = sin x。直角三角形 PHA において PH は斜辺 PA より短い(2巻)。そして弦 PA は、弧 AP の内接折れ線(点を打たない、いちばん粗いやつ)だから、sup の定義より弧長 x 以下。つなげて

$$\sin x = PH \le PA \le x$$

**右側: x ≤ tan x。**
A における接線(直線 x = 1)と P における接線の交点を T とする。T は角 ∠AOP の二等分線上にあり(接線の対称性、2巻)、AT = TP。

まず補題3(接線による外側からの評価)により、弧長 x ≤ AT + TP = 2·AT。

次に **2·AT ≤ tan x** を示す。A での接線と直線 OP の交点を Q とすると、直角三角形 OAQ において AQ = tan x(まさに tan の定義)。T は角 O の二等分線が辺 AQ と交わる点だから、**角の二等分線定理**(2巻3章)により

$$\frac{AT}{TQ} = \frac{OA}{OQ} = \cos x \le 1$$

(OQ = 1/cos x は直角三角形 OAQ での cos の定義そのもの。) よって AT ≤ TQ、すなわち T は AQ の中点より下にある。ゆえに 2·AT ≤ AQ = tan x。つなげて

$$x \le 2\,AT \le \tan x$$

まとめて、0 < x < π/2 で

$$\boxed{\ \sin x \le x \le \tan x\ }$$

登場した道具を数え上げてほしい。三角不等式、凸多角形の切断、接線、角の二等分線定理、三角比の定義 ── 全部2巻の住人で、面積はどこにもいない。

## 5.6　lim sin x/x = 1 ── 循環せずに証明する

**定理** $\displaystyle\lim_{x\to 0}\frac{\sin x}{x} = 1$

*証明。* まず 0 < x < π/2 とする。5.5の不等式を sin x > 0 と x > 0 で割り整理すると

$$\cos x \le \frac{\sin x}{x} \le 1$$

(左は x ≤ tan x = sin x/cos x の並べ替え、右は sin x ≤ x。)

あとは x → 0 で cos x → 1 を言えばよい。これも長さで済む: A から H までの距離は 1 − cos x で、直角三角形 AHP の斜辺は弦 AP だから

$$0 \le 1 - \cos x \le AP \le x$$

よって x → 0+ で cos x → 1。はさみうち(3章、4章で関数版に輸入済み)により sin x/x → 1。x → 0− は、sin が奇関数(5.4 で負の弧長へ鏡映により拡張済み)ゆえ sin x/x が偶関数であることから、右極限に帰着する。∎

これで背骨の急所は越えた。この極限は8章で「三角関数の微分」そのものになる: (sin x)′ = cos x の証明の心臓部が、いま示した式である。そして三角関数が微分できれば、マクローリン展開(14章)を経て、オイラーの等式(4巻11章)まで道は一本につながっている。

## 5.7　コラム: 教科書の面積による証明は、なぜ循環論法か

高校教科書の標準的な証明はこうだ。「扇形 OAP の面積は三角形 OAH と三角形 OAQ の間にあるから (1/2)sin x ≤ (1/2)x ≤ (1/2)tan x…」。図は美しく、議論は明快に見える。どこが問題なのか。

**扇形の面積 (1/2)x r² は、どこから来たか**を追跡すればよい。

1. 扇形の面積公式は、円の面積 πr² を中心角で按分したものである。
2. 円の面積 πr² は(厳密には)積分で証明される。
3. その積分の計算は、三角関数の微分(あるいは置換積分での三角関数の導関数)を使う。
4. 三角関数の微分の証明には、lim sin x/x = 1 が要る。
5. そして lim sin x/x = 1 の証明に、いま扇形の面積を使おうとしている。── 1 に戻る。

輪が閉じている。円の面積 → 積分 → sin の微分 → lim sin x/x → 扇形の面積 → 円の面積。どの環も前の環に寄りかかっており、全体を支える地面がない。

高校の教室では、円の面積は小学校以来の「事実」だから、この輪は見えない。嘘を教えているというより、**借用証書を貼らずに前借りしている**のが問題なのだ。本書の流儀で言えば、あの証明は〔借用: 円の面積(未証明)〕と明記すべき議論であり、そして借用先を辿ると自分に戻ってくる ── 返済不能な借金である。

切断の方法は一つしかない。輪のどこかを、輪の外から支えること。本書は「弧長」を内接折れ線の sup として独立に定義し(5.1)、そこを支点にした。おかげで円の面積 πr² は、11章で微積分の基本定理から**堂々と定理として**証明される(2巻5章の借用パートも、そこでまとめて回収される)。順番を入れ替えるだけで、同じ登場人物たちが循環のない一本の物語になる ── それがこの章のすべてである。

# 7巻 4章　連立一次方程式と掃き出し法

3巻1章の二直線の交点から始まった連立一次方程式を、$n$ 未知数 $m$ 式で扱う。解き方は一つ、消去である。この章の内容は紀元前から知られており(『九章算術』)、新しいのは「解の構造」の記述である。解があるか、いくつあるか、を階数という一つの数で答える。

**依存台帳**

- 〔借用〕なし
- 供給先: 本巻5章(行列式の計算)、本巻6章(固有ベクトルの計算)、9巻(数値線形代数・LU分解)
- 縦糸「特殊解+同次解」第3回(完結)

## 4.1　連立一次方程式の行列表現

$$\begin{cases}a_{11}x_1+\cdots+a_{1n}x_n=b_1\\\quad\vdots\\a_{m1}x_1+\cdots+a_{mn}x_n=b_m\end{cases}\quad\Longleftrightarrow\quad A\vec x=\vec b$$

$A$ は $m\times n$ 係数行列、$\vec x\in K^n$、$\vec b\in K^m$。解くとは、線形写像 $\vec x\mapsto A\vec x$ による $\vec b$ の逆像を求めることである。

## 4.2　ガウスの消去法

方程式に対して、解集合を変えない三つの操作(**行基本変形**)がある。

1. 二つの式を入れ替える。
2. 一つの式を 0 でない定数倍する。
3. 一つの式に他の式の定数倍を加える。

各操作は可逆なので、解集合は変わらない。$(A\mid\vec b)$(拡大係数行列)に対してこれを繰り返し、**階段形**(各行の最初の 0 でない成分 = 主成分が、下の行ほど右にあり、主成分の上下がすべて 0)に直す。これがガウスの消去法(掃き出し法)である。

例:

$$\begin{pmatrix}1&2&1&\mid&4\\2&5&3&\mid&10\\1&3&3&\mid&8\end{pmatrix}\to\begin{pmatrix}1&2&1&\mid&4\\0&1&1&\mid&2\\0&1&2&\mid&4\end{pmatrix}\to\begin{pmatrix}1&0&0&\mid&-2\\0&1&0&\mid&0\\0&0&1&\mid&2\end{pmatrix}$$

解 $(x_1,x_2,x_3)=(-2,0,2)$。

階段形は基本変形の順序によらず一意に決まる(既約階段形の一意性)。

## 4.3　解の存在と一意性、階数

**定義** $A$ の階段形の 0 でない行の個数を $A$ の**階数** $\operatorname{rank}A$ という。行基本変形は行空間を変えないので、階数は行空間の次元であり、それは列空間の次元(3章の像の次元)に等しい(行の階数 = 列の階数。証明は、階段形の主成分の列が列空間の基底になることによる)。

**定理 4.1(解の構造)** $A\vec x=\vec b$ について

1. 解が存在する $\iff\operatorname{rank}A=\operatorname{rank}(A\mid\vec b)$。
2. 解が存在するとき、解の全体は $\vec x_0+\operatorname{Ker}A$($\vec x_0$ は一つの解)。
3. $\dim\operatorname{Ker}A=n-\operatorname{rank}A$(次元定理)。したがって解がただ一つ $\iff\operatorname{rank}A=n$。

*証明。* 1: 階段形で「$0=b'_i\neq0$」の行が現れないこと。2: $A\vec x=A\vec x_0=\vec b$ なら $A(\vec x-\vec x_0)=\vec0$。3: 3章の次元定理。∎

**「特殊解 + 同次解」の完結。** 1巻11章の $ax+by=c$、5巻15章の $y'+py=q$、そしてここ。解集合は「一つの解」に「同次方程式の解空間(核)」を足した、部分空間の平行移動である。自由度は $n-\operatorname{rank}A$ で、階段形では主成分のない列に対応する未知数を自由に選べる。三つの実例は、線形写像の核という一つの概念で統一された。

**正方行列の場合。** $n\times n$ で $\operatorname{rank}A=n\iff\operatorname{Ker}A=\{\vec0\}\iff A$ は逆行列を持つ $\iff$ 任意の $\vec b$ に対して解がただ一つ。逆行列は $(A\mid I)$ を掃き出して $(I\mid A^{-1})$ にすれば得られる。3巻5章の $2\times2$ の公式はその特別な場合で、5章で行列式の言葉に翻訳される($\det A\neq0$)。

**一次独立性の判定(2章の宿題)。** $\vec v_1,\ldots,\vec v_k\in K^n$ が独立 $\iff$ それらを列に並べた行列の階数が $k$。掃き出せば分かる。

## 4.4　コラム: 『九章算術』の方程術

紀元前1世紀ごろに成立した中国の『九章算術』第八章「方程」は、連立一次方程式を係数の格子(算木を並べた盤)で表し、列(現代の行に相当)どうしの定数倍と減算で消去する。上の例と同じ手続きであり、負の数の演算規則(正負術)もそこに現れる ── 負の数がヨーロッパで受け入れられる1500年以上前である。「ガウスの消去法」の名はガウスが最小二乗法の計算で体系化したこと(1810年ごろ)によるが、手続き自体は方程術そのものである。関孝和(17世紀)の行列式(5章コラム)は、この伝統の上にある。

## 4.5　コラム: LU分解 ── 掃き出しの過程を記録しておく

掃き出しで使った「行 $i$ に行 $j$ の $c$ 倍を加える」操作を、下三角行列 $L$ に記録しておくと、$A=LU$($U$ は上三角の階段形)と書ける。すると $A\vec x=\vec b$ は $L\vec y=\vec b$、$U\vec x=\vec y$ という二つの三角行列の方程式に分かれ、どちらも代入だけで解ける($O(n^2)$)。右辺 $\vec b$ が何度も変わる問題(時間発展のシミュレーション、回路解析)では、分解を一度($O(n^3)$)やっておけば、以後は毎回 $O(n^2)$ で済む。

数値計算では、主成分が小さいと丸め誤差が爆発するので、大きい成分を主成分に選ぶ(ピボット選択)。$LU$ 分解の安定性と計算量は9巻の数値線形代数で扱う。理論(この章)と実装(9巻)の間には、有限桁の実数という壁がある。

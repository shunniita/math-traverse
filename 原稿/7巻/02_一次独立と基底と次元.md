# 7巻 2章　一次独立・基底・次元

「1 と $\sqrt2$ は独立している」(1巻9章)、「ベクトル空間の大きさ」、「自由度」。これらの感覚を一つの定義にする。一次独立、基底、次元。この章の主定理は「基底の元の個数は基底の取り方によらない」で、それがあって初めて「次元」という数が意味を持つ。

**依存台帳**
- 〔前提〕本巻1章 / 3巻1章(座標) / 4巻3章(多項式の一意性 ── 例として) / 0巻3章(帰納法)
- 〔借用〕なし
- 回収する借用証書: 1巻9章8節(「1 と √2 は独立」)、8巻6章2節(拡大次数 = 次元の定義)
- 供給先: 本巻3〜9章、8巻6〜7章

## 2.1　一次独立・一次従属

**定義** $v_1,\ldots,v_k$ が**一次独立**であるとは

$$c_1v_1+\cdots+c_kv_k=\vec0\ \Longrightarrow\ c_1=\cdots=c_k=0$$

が成り立つことをいう。そうでない(0 でない係数の組で $\vec0$ が作れる)とき**一次従属**という。

一次従属とは、どれかのベクトルが他のベクトルの線形結合で書けることと同値である($c_i\neq0$ なら $v_i$ について解ける)。「余分なベクトルがある」状態が従属、「どれも他から作れない」状態が独立である。

- $\mathbb{R}^2$ の $(1,0),(0,1)$ は独立。$(1,2),(2,4)$ は従属。
- $\mathbb{R}$ 上の $\mathbb{C}$ で、$1,i$ は独立($a+bi=0\Rightarrow a=b=0$、1巻10章)。
- $\mathbb{Q}$ 上の $\mathbb{R}$ で、$1,\sqrt2$ は独立。$a+b\sqrt2=0$、$b\neq0$ なら $\sqrt2=-\dfrac ab$ で無理性に反する(1巻9章8節)。**「1 と $\sqrt2$ は独立している」という感覚の正体は、$\mathbb{Q}$ 上の一次独立である。** $\mathbb{R}$ 上では $\sqrt2=\sqrt2\cdot1$ で従属になる。独立性は係数の体に相対的である。
- 多項式空間で $1,x,x^2,\ldots,x^n$ は独立(多項式が恒等的に 0 なら全係数 0 ── 4巻3章、$n$ 次多項式の根は $n$ 個以下)。
- 関数空間で $1,\cos x,\sin x$ は独立。$e^{x},e^{2x}$ も。$\sin^2x,\cos^2x,1$ は従属($\sin^2+\cos^2-1=0$)。

**判定の実務。** $\mathbb{R}^n$ の $k$ 本のベクトルの独立性は、係数を未知数とする同次連立一次方程式が自明解しか持たないか、という問いで、4章の掃き出し法で判定できる。

## 2.2　基底と次元

**定義** $V$ の部分集合 $B$ が**基底**であるとは、$B$ が一次独立で、かつ $V$ を生成することをいう。

基底とは「余分がなく、不足もない」生成系である。

- $K^n$ の標準基底 $e_1=(1,0,\ldots,0),\ldots,e_n$。
- $\mathbb{C}$ の $\mathbb{R}$ 上の基底 $\{1,i\}$。$\mathbb{Q}(\sqrt2)$ の $\mathbb{Q}$ 上の基底 $\{1,\sqrt2\}$。
- $K[x]_{\le n}$ の $\{1,x,\ldots,x^n\}$。テイラー展開(5巻14章)は、$\{1,(x-a),(x-a)^2,\ldots\}$ という別の基底に関する座標である。
- $y''=-y$ の解空間の $\{\cos x,\sin x\}$。$\{e^{ix},e^{-ix}\}$ も基底(4巻11章)。

**定理 2.1(基底の存在と一意性の型)** 有限個のベクトルで生成されるベクトル空間は基底を持つ。すべての基底は同じ個数の元からなる。

*証明。* 存在: 生成系から、他の線形結合で書けるベクトルを一つずつ除いていくと、有限回で一次独立な生成系に着く。

個数の一致は、次の補題による。**(取り替えの補題)** $v_1,\ldots,v_m$ が $V$ を生成し、$w_1,\ldots,w_k$ が一次独立なら $k\le m$。証明: $w_1$ を $v$ たちの線形結合で書き、係数が 0 でない $v_i$ を $w_1$ で置き換えても生成系のまま(解き直せる)。次に $w_2$ を新しい生成系で書き、係数が 0 でない $v_j$($w_1$ ではない ── $w_1,w_2$ が独立だから)を $w_2$ で置き換える。繰り返すと、$k>m$ なら $v$ が尽きて $w_{m+1}$ が $w_1,\ldots,w_m$ の線形結合になり、独立性に反する。

二つの基底 $B,B'$ について、$B$ は生成、$B'$ は独立なので $|B'|\le|B|$、逆も同様。∎

**定義** 基底の元の個数を $V$ の**次元**といい $\dim V$ と書く。有限のとき有限次元。

$\dim K^n=n$、$\dim_{\mathbb{R}}\mathbb{C}=2$、$\dim_{\mathbb{Q}}\mathbb{Q}(\sqrt2)=2$、$\dim K[x]_{\le n}=n+1$、$m\times n$ 行列の空間の次元は $mn$。$K[x]$、数列空間、関数空間は無限次元。

8巻6章で「拡大次数とは次元のことである」と述べ、次数の積公式を「基底の積が基底になる」ことで証明した。その「基底」「次元」がこの節で定義されたものである。ガロア理論の隠れた主役が線形代数だ、という8巻の言葉の根拠は、定理2.1にある。

**定理 2.2(次元の使い方)** $\dim V=n$ のとき

1. $n$ 本の一次独立なベクトルは基底である。
2. $n$ 本の生成系は基底である。
3. 部分空間 $W$ について $\dim W\le\dim V$、等号なら $W=V$。
4. $\dim(W_1+W_2)=\dim W_1+\dim W_2-\dim(W_1\cap W_2)$。

いずれも取り替えの補題から。4は「重なりを引く」で、2巻9章のオイラーの公式や6巻の包除原理と同じ型の勘定である。

## 2.3　座標(基底に関する成分)

**定理 2.3** $B=\{b_1,\ldots,b_n\}$ が基底なら、任意の $v\in V$ は $v=c_1b_1+\cdots+c_nb_n$ とただ一通りに書ける。

*証明。* 書けることは生成性。一意性: 二通りに書けたら、差をとって独立性に反する。∎

$(c_1,\ldots,c_n)$ を $v$ の $B$ に関する**座標**(成分)という。**基底を選ぶことは、$V$ を $K^n$ と同一視することである。** 座標をとる写像 $V\to K^n$ は全単射で、和とスカラー倍を保つ(3章の同型)。$n$ 次元ベクトル空間は、どれも $K^n$ と同型である。

ただし同一視は基底に依存する。基底を変えれば座標が変わる。3巻3章で「座標の選び方は一つではない」と述べたことが、ここで正確になる。極座標は線形な基底の取り替えではないが、「同じ点を別の目盛りで読む」という思想は同じである。

**基底の変換。** 二つの基底 $B,B'$ について、$B'$ の各元を $B$ で書いた係数を列に並べた行列 $P$(**変換行列**)により、座標は $\vec c=P\vec c\,'$ と変わる。$P$ は正則(逆変換がある)。6章の固有値、8章の対角化は、「座標が簡単になる基底を選ぶ」問題である。

**多項式の座標。** $K[x]_{\le n}$ の基底 $\{1,x,\ldots,x^n\}$ に関する $f$ の座標は係数列。基底 $\{1,(x-a),\ldots,(x-a)^n\}$ に関する座標はテイラー係数 $\dfrac{f^{(k)}(a)}{k!}$(5巻14章)。同じ多項式の、二つの基底での座標である。

**フーリエ係数(予告)。** 関数空間で $\{1,\cos x,\sin x,\cos2x,\sin2x,\ldots\}$ を「基底」とみなしたときの座標がフーリエ係数である(9章)。無限次元なので「基底」の意味に注意が要り、そこに内積(7章)が要る。

---

次元が定義され、1巻9章と8巻6章の借りが返った。次章では、ベクトル空間の間の「構造を保つ写像」、線形写像を扱う。3巻5章の行列がその表現であり、核と像の次元の収支(次元定理)が「潰した分で割る」縦糸の線形代数版になる。

# 1巻 1章　自然な数 ── 数えるという行為から

**1巻の玄関。** 本書はここから始めても読める。0巻は「自然数とは何か」を公理で固定する巻だったが、この章は「自然数はどう使われてきたか」から入る。同じ対象を、今度は道具として手に取る。

- 〔借用〕なし
- 供給先: 本巻2章(足し算)、本巻11章(整数論)、6巻1章(場合の数)

## 1.1　数はどのようにして生まれたか

羊が10頭いる。朝、囲いから出す。夕方、全部戻ってきたか知りたい。

「10」という言葉を持たない羊飼いにも、これはできる。朝、羊が一頭出るたびに小石を袋へ一つ入れる。夕方、羊が一頭戻るたびに小石を一つ出す。袋が空になれば全部戻った。小石が残れば、残った小石の分だけ羊が足りない。

この方法には数の名前が要らない。要るのは「羊一頭に小石一個」という**対応づけ**だけである。数を数えることの原型はここにある。

人類がこれをいつから始めたかは正確には分からないが、骨に刻み目を並べた道具は残っている。エスワティニの洞窟で見つかったレボンボの骨には29本の刻み目があり、放射性炭素年代測定で4万年以上前のものとされる([Wikipedia: Lebombo bone](https://en.wikipedia.org/wiki/Lebombo_bone))。刻み目が何を数えたかは推測の域を出ない。それでも「一つのできごとに一本の刻み目」という対応づけが、文字よりはるかに古いことは確かである。

袋の小石も骨の刻み目も、同じことをしている。数える対象そのもの(羊、日、獲物)から離れて、対応づけだけを別の場所へ記録する。この「離れる」動きが、数の抽象化の第一歩である。

## 1.2　1対1対応づけ、等号と不等号

小石の方法を言葉にし直す。

二つの集まり A と B があるとき、A の各元に B の元を一つずつ割り当て、B のどの元もちょうど一度だけ割り当てられているなら、この割り当てを A から B への**1対1対応**という。0巻2章の言葉では全単射である。

1対1対応がつけられるとき、A と B は「同じだけある」と言うことにする。羊と小石に1対1対応がつけば、羊は小石と同じだけいる。

ここで大事なのは、「同じだけある」を判定するのに、どちらの個数も知らなくてよいことである。数えられない羊飼いでも、袋の小石を見れば判定できる。

1対1対応がつかないときは、どちらかが余る。A の元をすべて B の元に割り当てたのに B に余りがあれば、B は A より多い。この関係を後で不等号 $<$ で書く。1対1対応がつく関係は等号 $=$ で書く。

つまり等号と不等号は、もともと「対応づけて余るかどうか」の記録である。2章で足し算を手に入れたあと、この関係は「足して届くかどうか」という計算可能な形に言い換えられる。

## 1.3　数は抽象的 ── 誰も「2」そのものは表せない

羊2頭、小石2個、刻み目2本。これらに共通するものを「2」と呼ぶ。

しかし「2」そのものを見せてほしいと言われると困る。紙に「2」と書けば、それは数字という記号であって数ではない。りんごを2個置けば、それはりんごであって数ではない。りんごを取り除いても2は残るはずなのに、残ったものは机だけである。

これは困ったことではなく、数の性質そのものである。数は「2個あるものすべて」に共通する性質を、ものから切り離して名づけたものだ。だから特定のものでは表せない。

0巻4章はこの事情を逆手に取った。「2とは何でできているか」を問わず、「2は1の次であり、1は0の次である」という関係だけで自然数を決めた。関係だけで決めたから、羊で実現しても小石で実現しても集合で実現しても、同じ自然数になる。0巻4章6節の同型の議論が、それを保証している。

本書で「自然数 2」と言うときは、常にこの抽象的な段のことを指す。「2個のりんご」は、その段を使った一つの応用にすぎない。

## 1.4　0、zero、ゼロ、零…

羊が一頭もいないとき、袋には小石が一つも入らない。「何もない」を数と呼ぶかどうかは、人類が長く迷った問いである。

数えるための数、つまり「一つ、二つ、三つ」は、一つから始まる。一頭もいない羊を数え始める人はいない。だから歴史上の数体系の多くは 1 から始まる。

一方、位取り記数法では「この位には何もない」を書く記号が要る。「二百三」を「23」と書けば「二十三」と区別がつかない。空いた位を埋める記号としての 0 は、この必要から生まれた。インドのバクシャーリー写本には、空位を表す点が使われている。オックスフォード大学ボドリアン図書館による放射性炭素年代測定では、写本の最古の部分が3世紀から4世紀のものと分かった([University of Oxford, Gardens, Libraries & Museums](https://www.glam.ox.ac.uk/article/carbon-dating-finds-bakhshali-manuscript-contains-oldest-recorded-origins-symbol-zero))。空位の記号としての 0 は、ここまで遡れる。

「何もない」を、他の数と同じように足したり掛けたりできる**数**として扱ったのは、それより後である。628年、ブラフマグプタの『ブラーフマスプタシッダーンタ』は、0 を含む計算規則を書き下した。「ある数に 0 を足しても変わらない」「0 に数を掛けると 0」といった規則である。この時点で 0 は、空位の記号から数へ昇格した。

本書では、0巻4章に従って**自然数は 0 から始まる**とする。$\mathbb{N}=\{0,1,2,3,\ldots\}$ である。学校の教科書や多くの日常的な用法では自然数を 1 から始めるが、どちらも規約であり、数学的に一方が正しいということはない。0 を含める理由は実務的で、「何もない状態」を計算の出発点に置くと、足し算の定義($a+0=a$)も、場合の数も、後の巻の数列の添字も、すべて簡潔になる。1 から始めたいときは「正の自然数」または「正の整数」と呼ぶ。

日本語では「ゼロ」も「零」も使う。「零」は「こぼれ落ちるわずかなもの」が原義で、「零細」の零である。「何もない」を表す字として選ばれた経緯は、数そのものとは別の話なので、ここでは深追いしない。

## 1.5　数の表し方と数え方、十進法：9の次が10だ

小石の袋は、羊が千頭になると重くて持てない。刻み目も、千本を一目で読める人はいない。数が大きくなると、数を**記録する方法**が問題になる。

刻み目を5本ごとに束ねる、10個の小石を大きな石1個に替える、といった工夫が各地で生まれた。十本の指で数える習慣から、10ごとに束ねる方式が広く定着した。これが十進法である。

十進法の要点は二つある。

1. **10種類の数字** 0, 1, 2, …, 9 を使う。
2. **位置が重さを決める。** 右から順に、一の位、十の位、百の位。同じ数字 3 でも、置く場所が違えば 3、30、300 を表す。

「9 の次が 10 だ」という一文には、この仕組みが凝縮されている。一の位で数字を使い切ったので、十の位を一つ進め、一の位を 0 に戻す。2桁目の「1」は「10 の束が一つ」、1桁目の「0」は「束にならなかった残りがない」を意味する。1.4 節の空位の 0 が、ここで働いている。

たとえば

$$2026 = 2\times1000 + 0\times100 + 2\times10 + 6$$

である。左辺は住所、右辺はその住所が指す自然数の中身である。

自然数と十進表記を混同しないでほしい。十進表記は自然数につけた**住所**であり、自然数そのものではない。同じ自然数を二進法で書けば別の住所になる。すべての自然数がちょうど一通りの十進表記を持つことは、0巻5章で確かめてある。この章ではその事実を使うだけにする。

数え方も表し方に引きずられる。日本語の「じゅういち、じゅうに」は「10 と 1、10 と 2」で、十進法の構造がそのまま音になっている。英語の eleven、twelve は語源的には「10 を超えて 1 残る、2 残る」だが、音からは十進構造が読み取りにくい。数の名前は言語の事情に左右され、数そのものは左右されない。

## 1.6　自然数の性質

ここまで来て、自然数の基本的な性質を並べておく。厳密な担保は 0巻4章のペアノの公理にあり、ここでは「使う側」の言葉で確認する。

**次がある。** どの自然数 n にも「次の数」$S(n)=n+1$ がある。羊が一頭増えれば小石が一個増える。だから自然数に最大のものはない。「一番大きい数」を持ってこられても、それに 1 を足したものを返せる。

**次はただ一つで、戻れる。** 次の数が同じなら元の数も同じである。つまり、数を一つ進める操作は一つに決まり、一つ戻す操作も(0 でなければ)一つに決まる。

**0 は誰の次でもない。** 数え始めの前には何もない。0 から一つ戻ることは、この章の装備ではできない。「0 からさらに引くとは何事か」という問いは3章で立て、8章で答える。

**0 から始めて次へ進めば、全部に届く。** これが帰納法の公理である(0巻3章6節、4章2節)。自然数に関する命題を証明するときの主力武器で、本巻でも繰り返し使う。使い方は「0 で成り立つことを確かめ、n で成り立てば n+1 でも成り立つことを確かめる」の二段だけである。

**大小は「対応づけて余るか」で決まる。** 1.2 節で見たように、二つの集まりの大小は1対1対応の余りで決まる。数の大小もこの延長にある。ただし「余る」を計算で扱うには足し算が要る。「a が b 以下であるとは、a に何かを足して b になることである」という言い換えは、2章で足し算の性質を揃えたあとに行う。

以上は、自然数を「数える道具」として使うときの最低限の性質である。この段階では、足し算は 0巻4章の定義があるだけで、その性質(順序を入れ替えてよいか、まとめて足してよいか)はまだ何も確かめていない。それが次章の仕事である。

## 1.7　コラム:「0」の起源

0 には二つの出自があり、この二つを混ぜると歴史が読めなくなる。

一つ目は**空位の 0**。位取り記数法で「この位は空」と示す記号である。バビロニアの六十進法にも空位を示す記号があったが、数の末尾には使われず、「10」と「1」の区別を文脈に頼る場面が残った。バクシャーリー写本の点は、この空位の記号として最古級の実例であり、年代測定によって従来の推定より数百年古いことが分かった。

二つ目は**数としての 0**。足したり掛けたりできる、他の数と同じ資格を持つ 0 である。ブラフマグプタが628年に規則を書き下したとき、彼は「0 で割る」も扱おうとして、$0\div0=0$ という今日では採らない規則を置いた。0 で割ってはいけない本当の理由は、5章で割り算を定義するときに、定義の側から分かる。

空位の 0 がなければ位取り記数法は成立せず、数としての 0 がなければ負の数も方程式も扱いにくい。どちらの 0 も、必要に押されて生まれた。数学の対象が「発見される」のか「発明される」のかは古い議論だが、0 については、少なくとも記号は発明され、規則は必要から選ばれた、と言える。

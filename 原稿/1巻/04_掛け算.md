# 1巻 4章　掛け算 ── 足し算をいっぱいする

$3+3+3+3$ と書くのが面倒なので $3\times4$ と書く。掛け算の発端はそれだけである。しかし「足し算の省略記法」として定義したものが、足し算とは独立の性質(交換・結合・分配)を持ち、位取り記数法と噛み合い、「順序を入れ替えてよいか」という論争まで生む。この章では定義から性質を証明し、論争には数学と規約を分けて答える。

**依存台帳**
- 〔前提〕本巻2章(足し算の性質・大小・三分法) / 本巻3章(引き算) / 0巻5章(十進法)
- 〔借用〕なし
- 供給先: 本巻5章(割り算)、本巻11章(素数・合同式)、4巻1章(多項式)
- 縦糸「代数構造」の第2回: 半環(4.9節)

## 4.1　同じ数をめっちゃ足す：3+3+3+3+…

一箱にみかんが3個入っている。箱が4つある。みかんは全部で何個か。

$3+3+3+3=12$ である。箱が40個なら $3+3+\cdots$ を40回書くことになる。書くのも読むのも辛い。そこで「3を4回足す」を $3\times4$ と書く約束をする。

ここで最初の注意がある。$3\times4$ の「3」と「4」は役割が違う。3は**足される数**、4は**足す回数**である。足し算では両方の数が同じ役割(袋の小石)だったが、掛け算の原風景では役割が非対称である。この非対称は、後で「交換法則」を証明するときに、証明が必要な理由そのものになる。

## 4.2　縦と横に並べてみる

みかんを並べ直す。3個ずつ4列に並べると、3行4列の長方形になる。

$$\begin{matrix}\circ&\circ&\circ&\circ\\circ&\circ&\circ&\circ\\circ&\circ&\circ&\circ\end{matrix}$$

横に見ると「4個が3行」、縦に見ると「3個が4列」。同じ12個である。首を90度傾けるだけで、$3\times4$ と $4\times3$ が同じ個数を指すことが**見える**。

これは交換法則の説得力ある説明であって、証明ではない。「見える」のは有限の並びについてであり、すべての自然数について同時に確かめたわけではない。ただし、この長方形の絵は、証明の方針を教えてくれる。「並べ方を変えても個数は変わらない」を、帰納法の言葉に翻訳すればよい。

## 4.3　掛け算とは：足し算をいっぱいする

定義する。足し算と同じく、二番目の数について再帰的に決める。

**定義(乗法)** 自然数 $a,b$ に対して

$$a\times0=0,\qquad a\times S(b)=a\times b+a$$

と定める。0巻4章の原始再帰の原理により、この規則を満たす $a\times b$ はただ一つ存在する。

一つ目は「0回足せば何もない」、二つ目は「回数を一つ増やせば、$a$ をもう一回足す」。$a\times b$ は「$a$ を $b$ 回足したもの」であり、4.1節の役割分担(左が足される数、右が回数)を定義に固定した。

$3\times2$ を定義だけで計算する。

$$3\times2=3\times S(1)=3\times1+3=(3\times S(0))+3=(3\times0+3)+3=(0+3)+3=6$$

以後、$a\times b$ を $ab$ とも書き、$a\cdot b$ とも書く。

### 掛け算の性質

証明の順序は、足し算のときと同じ型である。分配法則を先に、次に左側を増やす補題、それから交換法則。

**定理 4.1(分配法則)** $a(b+c)=ab+ac$。

*証明。* $c$ について帰納法。$c=0$ のとき、$a(b+0)=ab=ab+0=ab+a\cdot0$。

$c$ で成り立つとすると

$$a(b+S(c))=a\,S(b+c)=a(b+c)+a=(ab+ac)+a=ab+(ac+a)=ab+a\,S(c)$$

順に、足し算の規則2、乗法の規則2、帰納法の仮定、結合法則、乗法の規則2。∎

**定理 4.2(結合法則)** $(ab)c=a(bc)$。

*証明。* $c$ について帰納法。$c=0$ のとき両辺とも 0。$c$ で成り立つとすると

$$(ab)S(c)=(ab)c+ab=a(bc)+ab=a(bc+b)=a(b\,S(c))$$

三つ目の等号が分配法則である。∎

**補題 4.3** $0\times a=0$、$1\times a=a$、$S(a)\times b=ab+b$。

*証明。* いずれも $a$ または $b$ についての帰納法で、足し算のときの補題2.2と同じ形である。三つ目だけ書く。$b=0$ のとき両辺とも 0。$b$ で成り立つとすると

$$S(a)\,S(b)=S(a)b+S(a)=(ab+b)+S(a)=ab+(b+S(a))=ab+S(b+a)=ab+S(a+b)=ab+(a+S(b))=(ab+a)+S(b)=a\,S(b)+S(b)$$

途中で足し算の交換法則と結合法則を使った。∎

**定理 4.4(交換法則)** $ab=ba$。

*証明。* $b$ について帰納法。$b=0$ のとき、$a\cdot0=0=0\cdot a$。$b$ で成り立つとすると

$$a\,S(b)=ab+a=ba+a=S(b)\,a$$

最後が補題4.3。∎

長方形を90度回す操作は、帰納法に翻訳するとこの三行になる。

交換法則が出たので、分配法則は右からも成り立つ: $(b+c)a=ba+ca$。

### 掛け算と大小

**定理 4.5** $a\le b$ ならば $ac\le bc$。$c\neq0$ かつ $a<b$ ならば $ac<bc$。

*証明。* $a+d=b$ なら分配法則で $ac+dc=bc$、よって $ac\le bc$。後半は、$d\neq0$ かつ $c\neq0$ なら $dc\neq0$ であることを言えばよい。$d=S(d')$、$c=S(c')$ と書けば $dc=dc'+d=dc'+S(d')=S(dc'+d')\neq0$。よって $ac\neq bc$。∎

系として、**掛け算の消去法則**が出る。$c\neq0$ かつ $ac=bc$ なら $a=b$。三分法で $a<b$ か $b<a$ なら $ac\neq bc$ だから。$c=0$ のときに消去できない($3\times0=5\times0$ だが $3\neq5$)ことは、5章で「0 で割れない」につながる。

また、$ab=0$ ならば $a=0$ または $b=0$。定理4.5の証明中で示した「どちらも 0 でなければ積は 0 でない」の対偶である。

## 4.4　九九

定義だけで $7\times8$ を計算すると、足し算を8回、その各回を一つずつ進めるので、$S$ を56回作用させる。人間はそれをやらない。表を暗記する。

九九は、1から9までの積81個を暗記する制度である。十進法では各位の数字が 0 から 9 なので、この表さえあれば、どんな大きな数同士の掛け算も「一桁同士の積」と「足し算」と「桁のずらし」に分解できる。分解の根拠は分配法則と、次節の位取りの性質である。

交換法則のおかげで、実際に覚える必要があるのは81個の半分弱で済む。$7\times8$ を覚えれば $8\times7$ は要らない。定理4.4は暗記量を減らす定理でもある。

## 4.5　9の次は10だし、10をかけると0がいっこ増える

累乗の記法を用意する。

**定義(累乗)** $a^0=1$、$a^{S(n)}=a^n\times a$。

$a^n$ は「$a$ を $n$ 回掛けたもの」で、掛け算が「足し算を $n$ 回」だったのと同じ型の定義である。$10^0=1$、$10^1=10$、$10^2=100$、$10^3=1000$。

十進表記(0巻5章)とは、自然数 $n$ を

$$n=d_k10^k+d_{k-1}10^{k-1}+\cdots+d_110+d_0\qquad(0\le d_i\le9)$$

と書いたときの数字列 $d_kd_{k-1}\cdots d_0$ のことだった。これに 10 を掛ける。分配法則と累乗の定義により

$$10n=d_k10^{k+1}+d_{k-1}10^k+\cdots+d_110^2+d_010+0$$

各位の数字が一つ左の位へ移り、一の位に 0 が入る。「10 をかけると 0 がいっこ増える」は、十進表記の**桁がずれる**現象を一の位から見た言い方である。数が10倍になったのであって、0 という記号が増えたのはその十進表記上の見え方にすぎない。二進表記なら「2 をかけると 0 がいっこ増える」になる。

このずらしと九九と分配法則を組み合わせたものが筆算である。$23\times45$ は

$$(2\cdot10+3)(4\cdot10+5)=8\cdot10^2+10\cdot10+12\cdot10+15$$

を計算し、繰り上がりを処理して 1035 を得る。筆算のどの段も、この章の定理のどれかで正当化される。

## 4.6　掛け算は自由だ

「一箱3個のみかんが4箱」を $3\times4$ と書くか $4\times3$ と書くか。

日本の小学校では、しばしば「(一つ分の数)×(いくつ分)」の順で書くよう指導され、$4\times3$ と書くと減点される、という話が繰り返し議論になる。本書はこの問題に、次のように答える。

**数学の側。** 定理4.4により、すべての自然数 $a,b$ について $ab=ba$ である。$3\times4$ と $4\times3$ は同じ自然数 12 を指す。これは定義から証明された定理であり、意見の余地はない。

**規約の側。** 「一つ分を左に書く」は、式を書くときの**書式の約束**である。約束としては一貫していれば何でもよく、英語圏では "4 times 3" つまり「3 の 4 倍」と読んで $4\times3$ と書く流儀のほうがむしろ普通である。本書の定義 $a\times S(b)=a\times b+a$ も「左が足される数、右が回数」と決めたが、これは定義を書くための便宜であり、逆に決めても定理4.4に至る道筋は同じである。

**混同してはいけないこと。** 「順序を入れ替えると答えが変わる」は誤りである。「順序を入れ替えても式の意味は変わらない」も、書式の約束を採用している文脈では言いすぎである。書式の約束は、状況を式に翻訳するときの読みやすさのための規則であって、数学の定理ではない。約束を教えることと、約束を数学だと教えることは別で、本書が避けたいのは後者である。

2章4節で「誰も $2+3=5$ から元の状況を復元できない」と述べた。掛け算も同じで、$12$ からは「3 個が 4 箱」も「4 個が 3 箱」も「縦3横4の長方形」も復元できない。式は状況を忘れる。だから「$3\times2=6$ がどうしてそうなったか」は、式ではなく、式を書いた人に聞くしかない。

## 4.7　倍数、公倍数、最小公倍数

**定義** 自然数 $a$ に対し、$a\times k$($k$ は自然数)の形の数を $a$ の**倍数**という。$a$ と $b$ の両方の倍数を**公倍数**という。

0 はすべての数の倍数である($a\times0=0$)。0 でない公倍数は存在するか。$ab$ がそうである。では、0 でない公倍数のうち最小のものは存在するか。「最小」があると言うには、次の原理が要る。

**定理 4.6(最小元の原理)** 自然数の空でない部分集合には、最小の元が存在する。

*証明。* 対偶を示す。$A\subseteq\mathbb{N}$ が最小元を持たないとする。命題 $P(n)$ を「$n$ 以下の自然数はどれも $A$ に属さない」とする。$P(0)$: もし $0\in A$ なら 0 は最小元(0 は最小)だから、$0\notin A$。$P(n)\Rightarrow P(n+1)$: $n$ 以下が全部 $A$ の外なら、$n+1\in A$ とすると $n+1$ が $A$ の最小元になる($A$ の他の元は $n$ 以下ではないので、三分法と補題2.6' により $n+1$ 以上)。よって $n+1\notin A$。帰納法によりすべての $n$ で $P(n)$、つまり $A$ は空である。∎

したがって、$a,b$ がどちらも 0 でなければ、0 でない公倍数の集合は空でなく、最小元が存在する。それを**最小公倍数** $\mathrm{lcm}(a,b)$ と呼ぶ。最小公倍数の重要な性質(すべての公倍数は最小公倍数の倍数である)は、5章で割り算の余りを手に入れてから証明する。

最小元の原理は帰納法の言い換えであり、以後の巻で「最小の反例をとる」「最小の解をとる」という形で繰り返し現れる。無限降下法(12章)は、この原理を攻撃的に使ったものである。

## 4.8　コラム: 累乗、もっと累乗、もっともっと累乗…(そしてグラハム数へ)

足し算を繰り返して掛け算、掛け算を繰り返して累乗。この「繰り返し」をさらに繰り返すとどうなるか。

累乗を繰り返す操作を $a\uparrow\uparrow n$ と書く(クヌースの矢印記法)。$a\uparrow\uparrow3=a^{a^a}$ で、上から計算する。$3\uparrow\uparrow3=3^{27}=7625597484987$。矢印を一つ足すごとに「一つ前の操作を $n$ 回繰り返す」と定義する。$3\uparrow\uparrow\uparrow3=3\uparrow\uparrow(3\uparrow\uparrow3)$ は、3 の累乗の塔を約7兆6千億段積むことになり、十進法で書き下せる範囲を完全に超える。

グラハム数は、$g_1=3\uparrow\uparrow\uparrow\uparrow3$ から始めて、$g_{k+1}$ を「矢印を $g_k$ 本使った $3\uparrow\cdots\uparrow3$」と定め、$g_{64}$ としたものである。ラムゼー理論という組合せ論の問題の上界として登場した。この数の十進表記は、宇宙の全原子に一桁ずつ書いても足りない。

それでも $g_{64}$ は自然数であり、この章の定義の延長線上に厳密に定義されている。累乗の定義 $a^{S(n)}=a^n\times a$ と同じ型の再帰を、段数だけ増やしたにすぎない。0巻4章の原始再帰の原理は、これらすべての存在を保証する。「書き下せない」と「定義できない」は違う。

## 4.9　コラム: 半環

この章で証明した性質を、2章の足し算の性質と合わせて並べる。

- $(\mathbb{N},+)$ は 0 を単位元とする可換モノイド
- $(\mathbb{N},\times)$ は 1 を単位元とする可換モノイド
- 分配法則 $a(b+c)=ab+ac$ が二つを結ぶ
- $a\times0=0$

この四点を満たす構造を**半環**という。半環は「足し算と掛け算があり、両方結合し、分配法則で繋がっているが、引き算はできなくてよい」構造である。自然数は半環の代表例だが、他にもある。

- 集合の和集合と積集合。$\cup$ が足し算、$\cap$ が掛け算の役をする。分配法則 $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$ は0巻1章で見た。
- 「最小値」と「足し算」の組。$\min$ を足し算、$+$ を掛け算の役にすると、分配法則 $a+\min(b,c)=\min(a+b,a+c)$ が成り立つ。この半環は最短経路の計算(9巻)で主役になる。

半環に引き算を加えると環(8章コラム)になり、さらに 0 以外での割り算を加えると体(5章・9章コラム)になる。自然数から整数、有理数へと数の世界を広げる歩みは、代数構造の階段を一段ずつ上る歩みでもある。

---

掛け算が揃った。次章では、足し算に引き算があったように、掛け算に割り算を用意する。そして引き算のときと同じく、「いつでもできるわけではない」壁にぶつかる。ただし今度の壁は二重で、「割り切れない」という壁と、「0 では割れない」という壁がある。前者には「余り」という答えがあり、後者には答えがない。

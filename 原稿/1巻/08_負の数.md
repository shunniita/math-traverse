# 1巻 8章　0よりも小さい数：負(マイナス)の数

3章で「$3-5$ は自然数の中にない」と証明した。この章では、その外側に数を置く。置き方は7章と同じで、「まだ答えのない引き算」を組にして数と呼び、同値関係で整理する。できあがった整数では引き算がいつでもでき、足し算は群になる。そして $(-1)\times(-1)=1$ が、規約ではなく定理として出てくる。

## 8.1　負の数あれこれ

### 歴史：そんなもの存在してたまるか！

「何もない」より少ない数、という考えは長く拒まれた。羊が $-3$ 頭いる状況はないからである。

インドでは早くから受け入れられた。1章のコラムで触れたブラフマグプタは、628年の著作で「財産」と「負債」の計算規則を書いている。「負債と負債の積は財産」という規則もあり、これは $(-1)\times(-1)=1$ の最古級の記録である。

ヨーロッパでは17世紀になっても抵抗があった。方程式の負の解を「偽の根」と呼ぶ習慣が残り、負の数を正の数と同じ資格の数として扱うことには、ためらいがあった。数直線上に 0 の左側を描き、負の数を「向き」として理解する見方が広まって、ようやく市民権を得た。

拒まれた理由は明快である。数を「ものの個数」と思っている限り、負の個数は意味を持たない。負の数が意味を持つのは、数を「基準からのずれ」や「操作」として見たときである。

### 負債：つまり借金のことだ

持ち金 3 で 5 を払う。払えないが、払ったことにして「2 の借り」が残る、と考える。この「2 の借り」を $-2$ と書く。次に 5 稼げば、借りを返して手元に 3 残る: $-2+5=3$。

借金の計算は、負の数の計算規則をすべて満たしている。「借りが借りを生む」とか「借りを帳消しにする」といった日常語は、そのまま整数の演算に翻訳できる。

### 基準の0を下回ることもある：気温とか

温度計の 0 度は「何もない」ではなく、水が凍る点という**基準**である。基準より 3 度低い状態を $-3$ 度と呼ぶ。海抜、時差、得点差、みな同じ構造で、「0 は基準であって無ではない」。

この見方では、負の数は「反対向きの量」である。上へ 3 と下へ 3。右へ 3 と左へ 3。3章末で予告した数直線は、この見方を絵にしたものである。

## 8.2　ほんとうの「足し算の逆」：2+(-2)=0

7章で「$2\times\dfrac12=1$」と書けたとき、掛け算は本当に元へ戻せるようになった。同じことを足し算でやりたい。$2+x=0$ を満たす $x$ を作り、$-2$ と名づける。$-2$ を 2 の**反数**、または加法逆元と呼ぶ。

作り方は7章と同じである。答えのない引き算 $a-b$ を組 $(a,b)$ として保管し、「同じ差を表す組」を同一視する。

**定義(整数)** 自然数の組 $(a,b)$ を考える。$(a,b)$ と $(c,d)$ は、$a+d=b+c$ のとき同値であるとする。この同値類の全体を**整数**といい、$\mathbb{Z}$ と書く。

「$a-b=c-d$ ならば $a+d=b+c$」を、引き算を使わずに書いたものが同値の条件である。これが同値関係であることは、6章5節の証明で掛け算を足し算に、消去法則を2章の消去法則に置き換えればよい。

組 $(a,b)$ の同値類を、ひとまず $[a,b]$ と書く。$[5,3]$ は「$5-3$」、$[3,5]$ は「$3-5$」の代わりである。自然数 $n$ は $[n,0]$ と同一視する。$[0,n]$ が $-n$ である。どの整数も $[a,0]$ か $[0,b]$ の形の代表を持つ(三分法により $a\ge b$ か $a<b$ で、大きいほうから小さいほうを引けばよい)。だから整数は「自然数とその反数」の全体である。

$$\mathbb{Z}=\{\ldots,-3,-2,-1,0,1,2,3,\ldots\}$$

## 8.3　整数

**定義(足し算)** $[a,b]+[c,d]=[a+c,b+d]$。

well-defined の確認(7章3節)は自然数の足し算の法則だけで済む。

**定理 8.1** 整数の足し算は交換・結合法則を満たし、$0=[0,0]$ が単位元であり、**どの整数にも反数がある**: $[a,b]+[b,a]=[a+b,a+b]=[0,0]=0$。

$[a,b]$ の反数を $-[a,b]=[b,a]$ と書く。特に $-[n,0]=[0,n]$ で、$n+(-n)=0$。$2+(-2)=0$ は定理である。

これで $(\mathbb{Z},+)$ は群(7章コラム)になった。足し算が「必ず戻せる」世界である。

**大小** $[a,b]\le[c,d]$ を $a+d\le b+c$ で定める。代表によらないことと、順序の性質(反射・推移・反対称・三分法)は、自然数の対応する性質から出る。$-3<-1<0<1<3$ であり、0 より大きい整数を正、小さい整数を負という。負の数どうしでは、絶対値(0 からの距離)が大きいほど小さい。

## 8.4　整数の加減算：実はもう引き算と足し算は同一

**定義(引き算)** $x-y=x+(-y)$。

3章では引き算を「$y$ に何を足せば $x$ になるか」と定義した。整数ではその解が常に存在し($x+(-y)$ がそう: $y+(x+(-y))=x+(y+(-y))=x$)、一つに決まる(消去法則は群では自動的に成り立つ: $y+u=y+v$ なら両辺に $-y$ を足す)。だから「$-y$ を足す」を引き算と呼んでよい。

つまり整数の世界では、引き算は独立の演算ではなく、足し算の一種である。$5-3=5+(-3)=2$、$3-5=3+(-5)=-2$。「小−大」の壁はない。$-(-x)=x$ も、$(-x)+x=0$ から反数の一意性で出る。

3章で「引き算は結合しない」と述べた。整数でもそれは変わらないが、理由が透明になる。$a-b-c=a+(-b)+(-c)$ で、足し算としては結合するので、括弧の位置ではなく「どの数に反数の印がついているか」だけを追えばよい。$a-(b-c)=a+(-(b+(-c)))=a+(-b)+c$ である。

## 8.5　整数の乗算

掛け算を定義する。$(a-b)(c-d)=ac-ad-bc+bd$ という「欲しい結果」を、引き算なしで書く。

**定義(掛け算)** $[a,b]\times[c,d]=[ac+bd,ad+bc]$。

well-defined の確認は自然数の分配法則で済む。交換・結合・分配法則、$1=[1,0]$ が単位元であることも、代表で計算すれば確かめられる。

定義から次の三つが**定理として**出る。

### (−2)×3

$[0,2]\times[3,0]=[0\cdot3+2\cdot0,\;0\cdot0+2\cdot3]=[0,6]=-6$。

借金 2 が 3 回で借金 6。これは分配法則からも出る: $(-2)\times3=(-2)+(-2)+(-2)=-6$。

### 2×(−3)

$[2,0]\times[0,3]=[0,6]=-6$。交換法則から前項と同じ値になる。「2 を $-3$ 回足す」という言い方は意味をなさないが、交換法則が意味を与える。

### (−1)×(−1)

$[0,1]\times[0,1]=[0\cdot0+1\cdot1,\;0\cdot1+1\cdot0]=[1,0]=1$。

定義から計算しただけである。しかし「なぜ定義をそう決めたか」には理由がある。分配法則を保ちたいからである。もし分配法則が成り立つなら

$$0=(-1)\times0=(-1)\times(1+(-1))=(-1)\times1+(-1)\times(-1)=-1+(-1)\times(-1)$$

両辺に 1 を足して $(-1)\times(-1)=1$。つまり、負の数を含めても分配法則を維持する、と決めた瞬間に、$(-1)\times(-1)=1$ は選択の余地なく決まる。「なぜ負×負が正か」への本書の答えは、「分配法則を壊さない整数の掛け算は、それ以外にない」である。

一般に $(-a)\times b=-(ab)$、$(-a)\times(-b)=ab$。符号だけ別に決め、絶対値を掛ける、という学校の規則の正体である。

**掛け算と大小。** 正の数を掛けても大小は保たれるが、負の数を掛けると**逆転する**。$1<2$ の両辺に $-1$ を掛けると $-1>-2$。2章5節(定理2.7)で「掛け算については生き残らない場面がある」と予告したのはこれである。不等式の両辺に負の数を掛けたら向きを変える、という規則は、$(-1)\times(-1)=1$ と同じ根から出る。

**消去法則。** $c\neq0$ かつ $ac=bc$ なら $a=b$。$(a-b)c=0$ から、整数でも「積が 0 なら少なくとも一方が 0」が成り立つ(自然数の場合に帰着)。

## 8.6　整数の除算：それと負の分数

整数の割り算は、自然数のときと同じく、割り切れる場合しかできない。$-6\div3=-2$ は $3\times(-2)=-6$ による。

割り切れない場合の答えを数にするには、7章と同じ拡張を整数の上で行う。

**定義(有理数)** 整数 $p$ と 0 でない自然数 $q$ の組 $(p,q)$ を、$pq'=p'q$ のとき同値として、同値類を $\dfrac pq$ と書く。この全体を**有理数**といい、$\mathbb{Q}$ と書く。

分母を正に限ったのは、大小の定義を7章のまま使うためである($\dfrac pq\le\dfrac{p'}{q'}\iff pq'\le p'q$)。$\dfrac{-2}{3}$ を $-\dfrac23$ と書き、$\dfrac{2}{-3}$ はこれと同じ数の別記法とする。

四則は7章の定義をそのまま整数係数で使う。すると

- 足し算は群(反数 $-\dfrac pq=\dfrac{-p}q$)
- 0 以外の掛け算は群(逆数 $\dfrac qp$、ただし $p<0$ なら $\dfrac{-q}{-p}$ と分母を正に直す)
- 分配法則

がすべて成り立つ。これが5章コラムで予告した**体**の姿である。$\mathbb{Q}$ では、0 で割ること以外の四則がすべて自由にできる。

## 8.7　余りを考えるときは？

$-7$ を 3 で割ると、商と余りはどうなるか。「余りは 0 以上、割る数未満」という5章の条件を守るなら

$$-7=3\times(-3)+2$$

で、商 $-3$、余り $2$。$-7=3\times(-2)+(-1)$ と書くほうが直感的に見えるかもしれないが、余りが負では「余り」の意味(取り切れなかった残り)から外れ、一意性も壊れる。

**定理 8.2(整数の割り算の原理)** 整数 $a$ と正の整数 $b$ に対して、$a=bq+r$、$0\le r<b$ を満たす整数の組 $(q,r)$ がただ一つ存在する。

*証明。* $a\ge0$ なら定理5.2。$a<0$ なら $-a>0$ を割って $-a=bq'+r'$。$r'=0$ なら $a=b(-q')+0$。$r'>0$ なら $a=b(-q'-1)+(b-r')$ で、$0<b-r'<b$。一意性は定理5.2と同じ議論。∎

余りを 0 以上に固定すると、$-7$ も $2$ も「3 で割った余りが 2」の仲間になる。この分類が11章の合同式の土台であり、余りを負に取ると分類が壊れる。

計算機の言語には、負の数の割り算で余りの符号を割られる数に合わせる(いわゆる切り捨て除算)ものと、数学の定義どおり 0 以上にする(床除算)ものがある。$-7$ を 3 で割ると、前者は商 $-2$ 余り $-1$、後者は商 $-3$ 余り $2$ を返す。プログラムで余りを使うときは、どちらの規約かを確かめる必要がある(9巻)。

## 8.8　コラム: 環

整数の構造をまとめる。

- $(\mathbb{Z},+)$ は可換群
- $(\mathbb{Z},\times)$ は 1 を単位元とする可換モノイド
- 分配法則が二つを結ぶ

この三点を満たす構造を**環**という(乗法が可換なので、正確には可換環)。半環(4章コラム)に「足し算の逆元」を加えたものである。整数は環の代名詞で、記号 $\mathbb{Z}$ はドイツ語の Zahlen(数)に由来する。

環の例は多い。多項式(4巻)は環である。$n$ で割った余りの集合 $\{0,1,\ldots,n-1\}$ に「足して余りを取る」「掛けて余りを取る」を入れたものも環で、11章の合同式はこの環の計算である。正方行列(7巻)も環だが、掛け算が可換でない。

環では $(-1)\times(-1)=1$ が公理から証明できる。8.5節の四行の計算は、整数の性質を何も使わず、分配法則と単位元と反数の性質だけを使った。だから多項式でも行列でも余りの環でも、同じ式が成り立つ。「負×負=正」は整数の癖ではなく、環の定理である。

## 8.9　コラム: 負×負=正の説明いろいろ

$(-1)\times(-1)=1$ の説明は、聞き手に応じて何通りもある。並べて、それぞれが何を根拠にしているかを見る。

**借金の帳消し。** 「毎日 1 の借金が増える」を $-1$ を掛ける操作とみなし、「その逆、つまり 1 日戻す」をもう一つの $-1$ とみなすと、1 日戻せば借金は 1 減る、すなわち財産が 1 増える。根拠は「反対の反対は元」という向きの反転で、群の $-(-x)=x$ に対応する。

**九九の表の続き。** $3\times(-1)=-3$、$2\times(-1)=-2$、$1\times(-1)=-1$、$0\times(-1)=0$ と、左の数を 1 減らすごとに答えは 1 増える。この規則性を続ければ $(-1)\times(-1)=1$。根拠は「パターンの継続」で、数学的には分配法則 $(a-1)\times(-1)=a\times(-1)-(-1)$ の言い換えである。

**数直線上の回転。** $-1$ を掛けることを「数直線を 0 のまわりに 180 度回す」とみなすと、二回回せば元に戻る。根拠は幾何的な像で、10章で複素数の $i$ を「90 度回転」とみなす見方の前身になる。

**環の公理から。** 8.5節の四行。根拠は分配法則のみ。これが最も一般的で、整数の外でも通用する。

どの説明も間違いではない。ただし前三者は「なぜそう定義したいか」の説明であり、最後だけが「そう定義せざるを得ない」ことの証明である。学校で習う説明の多くは前者で、それは定義の動機として正しい。本書が付け加えるのは、動機とは別に、分配法則を要求した時点で答えが一意に決まる、という事実である。

数の世界は $\mathbb{N}\subset\mathbb{Z}\subset\mathbb{Q}$ と広がり、$\mathbb{Q}$ では 0 で割る以外の四則が自由になった。有理数は稠密で、どんな二つの間にも別の有理数がある。それでも足りない。7章末で見た「循環しない無限小数」は $\mathbb{Q}$ の中にない。次章では、正方形の対角線がその具体例であることを証明し、有理数の隙間を埋める。埋めた先の数の集まりが実数であり、その決定的な性質、完備性が、5巻の弧長と π を支える。

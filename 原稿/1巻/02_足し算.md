# 1巻 2章　足し算 ── 合わせる操作の性質を全部確かめる

$3+5$ と $5+3$ が同じであることを、誰も疑わない。この章はそれを疑うところから始める。疑うのは結論ではなく、「なぜ同じか」を一度も言葉にしたことがないという事実である。足し算の性質を、0巻の定義から一つずつ証明する。ついでに、大小関係を足し算で言い直し、後の巻で無言に使う道具(消去、三分法)を揃える。

**依存台帳**
- 〔前提〕0巻4章(加法の再帰的定義、$0+a=a$、$a+1=S(a)$) / 0巻3章(数学的帰納法) / 本巻1章
- 〔借用〕なし
- 供給先: 本巻3章(引き算)、本巻4章(掛け算)、5巻1章(数列)、7巻(線形性)
- 縦糸「代数構造」の第1回: 半群・モノイド(2.6節)

---

## 2.1　今あるものにさらにものを加えると、増える

袋に小石が3個ある。そこへ2個入れる。袋には5個ある。

これが足し算の原風景である。「今あるもの」に「加えるもの」を合わせて「合計」を得る。ここで注意したいのは、3個の袋に2個を**一個ずつ**入れていることだ。1個入れて4個、もう1個入れて5個。「2を足す」は「1を足すを二回」に分解できる。

この分解が、0巻4章で足し算を再帰的に定義したときの心である。

$$a+0=a,\qquad a+S(b)=S(a+b)$$

一つ目は「何も加えなければそのまま」、二つ目は「加える数を一つ増やせば、合計も一つ増える」。定義は袋の操作を、そのまま記号にしたものである。

## 2.2　左右から同時にやってきた、合計は？

橋の上に立っている。左から3人、右から5人が歩いてくる。橋の上には何人いるか。

8人である。誰も迷わない。しかし「3+5」と書くか「5+3」と書くかは迷う。左から来た人を先に数えるか、右を先にするか。どちらで書いても8人だと**知っている**が、それは経験の蓄積であって、証明ではない。

足し算の定義は左右対称ではなかった。$a+S(b)=S(a+b)$ は「右側の数を一つ増やすと合計が一つ増える」としか言っていない。左側の数を一つ増やしたときにどうなるかは、定義に書いていない。$3+5$ と $5+3$ が同じであることは、定義から**導く**必要がある。それを2.5節で行う。

## 2.3　足し算とは

改めて、本書の足し算を確認する。自然数 $a,b$ に対し、$a+b$ は次の二つの規則で決まる自然数である。

1. $a+0=a$
2. $a+S(b)=S(a+b)$

0巻4章の原始再帰の原理により、この規則を満たす $a+b$ はどの $a,b$ に対してもただ一つ存在する。定義から直ちに出る式も再掲する。

$$0+a=a,\qquad a+1=S(a)$$

前者は帰納法で証明した定理、後者は $1=S(0)$ からの計算である。以後、$S(a)$ と $a+1$ は同じものとして使う。

$3+2=5$ を定義だけで計算すると

$$3+2=3+S(1)=S(3+1)=S(S(3+0))=S(S(3))=S(4)=5$$

となる。袋に小石を一個ずつ入れる操作と、行数が一致している。

## 2.4　足し算は抽象的 ── 誰も「2+3=5」から元の状況を復元できない

「2+3=5」を見せられても、それが小石の話か、人の話か、日数の話かは分からない。足し算は状況から**数だけ**を取り出して計算する。だから同じ式が無数の状況に使える。

この抽象性は強みだが、注意点も生む。「2 個のりんごと 3 個のみかんを足すと 5」は正しいが、答えの 5 は「くだもの 5 個」であって「りんご 5 個」ではない。足し算は数を足すのであり、単位を揃えるのは足し算の外の仕事である。「2 メートルと 3 秒を足す」に意味がないのは、足し算の欠陥ではなく、単位を揃えられないからである。

ここに「1 つの式から状況は復元できない」という事実の裏面がある。式は状況を忘れる。忘れるから汎用になる。忘れた分は、式を使う人が補わなければならない。

## 2.5　足し算の性質

いよいよ証明する。使う道具は、定義の二つの規則と帰納法だけである。証明の順番が大事で、結合法則を先に済ませないと交換法則の証明が回らない。

### 結合法則

**定理 2.1(結合法則)** すべての自然数 $a,b,c$ に対して $(a+b)+c=a+(b+c)$。

*証明。* $a,b$ を固定し、$c$ について帰納法を使う。

$c=0$ のとき、$(a+b)+0=a+b$ であり、$a+(b+0)=a+b$。両辺が一致する。

$c$ で成り立つと仮定する。すると

$$(a+b)+S(c)=S((a+b)+c)=S(a+(b+c))=a+S(b+c)=a+(b+S(c))$$

一つ目と三つ目の等号は定義の規則2、二つ目は帰納法の仮定、四つ目は規則2を右から左へ使った。よって $S(c)$ でも成り立つ。∎

結合法則があるので、$a+b+c$ と括弧なしで書いてよい。どこで区切っても同じだからである。

### 左側を一つ増やす補題

定義は右側の数を一つ増やす規則しか持っていない。左側についても同じことが言えるかを、先に確かめる。

**補題 2.2** すべての自然数 $a,b$ に対して $S(a)+b=S(a+b)$。

*証明。* $a$ を固定し、$b$ について帰納法。

$b=0$ のとき、$S(a)+0=S(a)=S(a+0)$。

$b$ で成り立つと仮定すると

$$S(a)+S(b)=S(S(a)+b)=S(S(a+b))=S(a+S(b))$$

一つ目は規則2、二つ目は帰納法の仮定、三つ目は規則2を右から左へ。∎

### 交換法則

**定理 2.3(交換法則)** すべての自然数 $a,b$ に対して $a+b=b+a$。

*証明。* $a$ を固定し、$b$ について帰納法。

$b=0$ のとき、$a+0=a$ であり、$0+a=a$ は0巻4章の定理。よって $a+0=0+a$。

$b$ で成り立つと仮定すると

$$a+S(b)=S(a+b)=S(b+a)=S(b)+a$$

一つ目は規則2、二つ目は帰納法の仮定、三つ目は補題2.2を右から左へ。∎

橋の上の8人は、これで証明された。3+5 と 5+3 は、定義から同じ数に届く。

### 消去法則

**定理 2.4(消去法則)** 自然数 $a,b,c$ について、$a+c=b+c$ ならば $a=b$。

*証明。* $c$ について帰納法。

$c=0$ のとき、$a+0=b+0$ は $a=b$ そのもの。

$c$ で成り立つと仮定する。$a+S(c)=b+S(c)$ なら、規則2により $S(a+c)=S(b+c)$。$S$ は単射(ペアノの公理)だから $a+c=b+c$。帰納法の仮定より $a=b$。∎

交換法則があるので、$c+a=c+b$ からも $a=b$ が出る。「両辺から同じものを引く」という操作の正体はこれである。引き算はまだ定義していないが、消去はできる。

### 0 に足して 0

**補題 2.5** 自然数 $a,b$ について、$a+b=0$ ならば $a=0$ かつ $b=0$。

*証明。* $b\neq0$ なら、0巻4章の公理により $b=S(d)$ となる $d$ がある(0 でない自然数は誰かの次である。これは帰納法で示せる)。すると $a+b=S(a+d)\neq0$ となり仮定に反する。よって $b=0$、したがって $a=a+0=0$。∎

### 大小を足し算で言い直す

1章で「大小は対応づけて余るかで決まる」と述べた。「余る」を足し算で書く。

**定義** 自然数 $a,b$ について、$a+c=b$ となる自然数 $c$ が存在するとき、$a\le b$ と書く。さらに $a\le b$ かつ $a\neq b$ のとき $a<b$ と書く。

$a\le b$ の $b$ 側にある「余り」が $c$ である。この定義から、次が順に出る。

- **反射律** $a\le a$。$c=0$ をとればよい。
- **推移律** $a\le b$ かつ $b\le c$ なら $a\le c$。$a+d=b$、$b+e=c$ なら結合法則より $a+(d+e)=c$。
- **反対称律** $a\le b$ かつ $b\le a$ なら $a=b$。$a+c=b$、$b+d=a$ なら $a+(c+d)=a=a+0$、消去法則より $c+d=0$、補題2.5より $c=0$、よって $a=b$。
- **0 は最小** $0\le a$。$0+a=a$ による。
- **次は真に大きい** $a<S(a)$。$a+1=S(a)$ であり、$S(a)\neq a$ は帰納法で示せる。

**定理 2.6(三分法)** どの自然数 $a,b$ についても、$a<b$、$a=b$、$b<a$ のうちちょうど一つが成り立つ。

*証明。* まず「少なくとも一つ」を示す。示すべきは $a\le b$ または $b\le a$ である。$a$ について帰納法を使い、命題「すべての $b$ について $a\le b$ または $b\le a$」を示す。

$a=0$ のとき、$0\le b$ が常に成り立つ。

$a$ で成り立つと仮定し、任意の $b$ をとる。仮定より $a\le b$ または $b\le a$。

$b\le a$ の場合、$a\le S(a)$ と推移律より $b\le S(a)$。

$a\le b$ の場合、$a+c=b$ となる $c$ がある。$c=0$ なら $b=a\le S(a)$。$c=S(d)$ なら

$$b=a+S(d)=S(a+d)=S(a)+d$$

最後の等号は補題2.2。よって $S(a)\le b$。

いずれの場合も $S(a)$ について主張が成り立つ。

次に「多くとも一つ」を示す。$a<b$ と $a=b$ は定義から両立しない。$a<b$ と $b<a$ が両立すれば、反対称律より $a=b$ となって $a<b$ に反する。∎

三分法から、後で何度も使う小さな事実が出る。

**補題 2.6'** $a<b$ ならば $a+1\le b$。

*証明。* $a+c=b$、$c\neq0$ だから $c=S(d)$ と書け、$b=a+S(d)=S(a+d)=(a+1)+d$。∎

「$a$ より真に大きい自然数は $a+1$ 以上」という、自然数に隙間がないことの表現である。有理数(7章)では成り立たない。

三分法は、次章で「引き算はいつも大−小」と言うときの根拠になる。「どちらが大きいか」は常に決まり、決まったほうから小さいほうを引ける。

### 足し算は大小を保つ

**定理 2.7** $a\le b$ ならば、どの $c$ についても $a+c\le b+c$。逆に $a+c\le b+c$ ならば $a\le b$。

*証明。* $a+d=b$ なら $(a+c)+d=(a+d)+c=b+c$ で、結合法則と交換法則を使った。逆は、$(a+c)+d=b+c$ から $(a+d)+c=b+c$、消去法則より $a+d=b$。∎

「不等式の両辺に同じ数を足してよい」の正体である。8章で負の数を入れても、足し算についてはこの性質が生き残る。掛け算については生き残らない場面が出てくる(8章5節)。

## 2.6　コラム: 半群、モノイド

この章で証明した性質のうち、結合法則だけを取り出してみる。

集合 $M$ と、$M$ の二つの元から $M$ の元を作る演算 $\ast$ があり、結合法則 $(x\ast y)\ast z=x\ast(y\ast z)$ が成り立つとき、$(M,\ast)$ を**半群**という。自然数と足し算は半群である。

さらに、どの $x$ に対しても $e\ast x=x\ast e=x$ となる元 $e$ があるとき、**モノイド**という。$e$ を単位元と呼ぶ。自然数と足し算は 0 を単位元とするモノイドである。

なぜ性質を切り出して名前をつけるのか。同じ性質を持つ別のものが、山ほどあるからである。

- 文字列と「つなげる」操作。"ab" と "cd" をつなげると "abcd"。結合法則が成り立ち、空文字列が単位元。ただし交換法則は成り立たない("ab"+"cd" と "cd"+"ab" は別)。
- 写像と合成(0巻2章)。結合法則が成り立ち、恒等写像が単位元。これも交換しない。
- 自然数と掛け算(4章)。単位元は 1。

半群やモノイドについて証明した定理は、これらすべてで一度に成り立つ。「結合法則しか使わなかった証明」は、結合法則があるどこでも通用する。本巻では章末ごとに、その章で手に入れた性質に対応する構造の名前を紹介していく。群(7章)、環(8章)、体(5章・9章)と続く。それらが本格的に主役になるのは8巻である。

交換法則のある半群・モノイドを**可換**という。自然数の足し算は可換モノイドである。可換であることは、この章の証明が示した通り、定義から出る定理であって、当たり前のことではない。文字列の例が示すように、結合するが交換しない演算は身近にある。

---

足し算の性質が揃った。結合、交換、消去、そして大小。次章では「合わせる」の逆、「取り去る」を扱う。取り去りすぎると 0 を下回るが、自然数の世界に 0 の下はない。その壁にぶつかるところまでが、次章の範囲である。
